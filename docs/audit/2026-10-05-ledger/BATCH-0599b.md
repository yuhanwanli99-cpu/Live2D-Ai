# BATCH-0599b 落盘（极简）· Space.s2 = 8，且 tokens.dart 第 750 行

## 编号
`BATCH-0599.md` 已存在 ⇒ 本批落 `BATCH-0599b.md`。

## 命令（只读）
```
ls AUDIT-REPO/BATCH-0599.md
grep -rn "s2 = |s2 =" lib/design/*.dart lib/ui/*.dart
```

## 结果
```
design/tokens.dart:750  static const double s2 = 8;
```
⇒⇒⇒⇒ **`Space` 与 `tokens.dart` 在第 750 行** ⇒⇒ 若按 500 行上限看，**这一类**是超的
（但上限是 Rust-only，见 B0007 / B0569 ⇒ **Dart 不受约束**）。

## 三个可核点
1. **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ `s2 = 8` 被用作气泡的**最小宽度**下界**
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 判据：把一个**间距令牌**当**尺寸下界**用，
   在语义上是对的**（8 px 本来就是最小可读留白）
   ⇒⇒ 与 B0598b 第 ① 点「边界的值也从令牌系统取」**是同一条纪律的正例**。
2. **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 而 480 也可能是令牌（`tokens.dart` 第 750 行说明那文件很长）**
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 本批只 grep 到 `s2`，没 grep 到 `kBubbleReadingWidth` 在 tokens 里**
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 也就是说 480 是**本文件本地定义**的，不是令牌
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 判据：本地常量与令牌要能一眼分开**
   ⇒⇒ ⇒⇒ 本仓这一点做得好（`k` 前缀 + 定义在同一文件 `:295`）
   ⇒⇒ ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 与 s2 的对比很说明问题：
   `Space.s2`（令牌，前缀 `Space.`）vs `kBubbleReadingWidth`（本地，前缀 `k`）**
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 判据：命名前缀就是「这东西从哪来」的说明书。**
3. **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ medium 档面板宽本批未核**（`:294` 只交代 340 的情形）
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ ⇒ 保持未核，不猜** ⇒⇒
   **⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 判据：`:294` 明说「面板被拉宽时它才开始起作用」，
   而 medium 的面板宽未知 ⇒⇒ **本条的适用性只能说到 expanded 档。**
