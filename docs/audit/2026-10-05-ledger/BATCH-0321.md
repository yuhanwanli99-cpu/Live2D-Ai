## 本批产出：**0 条新发现**；⭐ **一条此前没被单独记过的纪律**
```dart
/// `GET /api/v1/logs`（**需 `dev_mode=true`**，否则 403 `dev_mode_required`）。
/// # 为什么**没有** `level` / `limit` 参数（2026-09-11）
/// 它们曾经被发出去，但服务端**根本不读查询参数**：`handle_logs()` 只按内置的 `MAX_LINES` 截尾，
/// 没有解析 `?limit=`。于是这两个参数有两个问题——一是「**静默无效**」（发的人以为有用），
/// 二是当时路由是精确匹配，带上 `?...` 会直接掉到 **501**，
/// 整个诊断面板的日志区**在成品里从来没拿到过数据**。
/// 501 已在服务端修掉（请求入口统一剥查询串，见 `web_api::strip_query`）。
/// 这里把没用的参数**删掉**而不是留着：**服务端既然不支持，客户端就不该假装支持**；
/// 哪天要限流行数，应该**服务端实现并写进契约**。                    // :96-107
```
五个可核点：
1. ⭐⭐ **两个参数被删掉、而不是留着** ⇒ ⇒ 「**客户端就不该假装支持**」
   ⇒ ⇒ **这是 AGENTS rc.2 ②「capabilities 去广告（删掉**假广告**）」的同一族，
   **而且发生在真实的 HTTP 调用上** ⇒ ⇒ **假广告不只在 capability 声明里**
2. ⭐⭐ **「静默无效」被点名**（「**发的人以为有用**」）⇒ ⇒ 那是 P9 家族（B0227/B0284 那条）
   ⇒ ⇒ **且用一个日期标记（2026-09-11）**
3. ⭐⭐ **501 的成因链写全了**：`?limit=` ⇒ 路由精确匹配 ⇒ **掉到 501**
   ⇒ ⇒ **诊断面板的日志区在成品里从来没拿到过数据**
   ⇒ ⇒ ⭐ **这正是 AGENTS v0.5.1 ③ 记的那个真缺陷**（**两处独立记载同一件事**）
4. ⭐⭐ **修法被点名在服务端**（`web_api::strip_query`）⇒ ⇒ **又一次「指路」**
5. ⭐ **「哪天要限流行数」的前置条件也给了**：「应该**服务端实现并写进契约**」
   ⇒ ⇒ **不是「以后客户端加个参数」，而是「先改契约」**

⇒ ⇒ ⭐ **可提炼（P29）**：**「服务端不支持的客户端参数，要删掉而不是留着」** ——
留着的代价是**每一次调用都在假装支持**，而**假装支持是最难被发现的失效**
（它不报错、只是没用）⇒ 与 B0293「**别假装有话说**」**同族：一个朝下（多说），一个朝外（多要）」
