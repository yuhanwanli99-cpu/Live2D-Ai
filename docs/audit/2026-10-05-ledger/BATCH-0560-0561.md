## B0561 · registry.rs 只有 25 行、一个 trait 三个方法
```
:9   pub struct SubscriptionId(pub u64);
:16  pub trait ModRegistrar {
:17    /// 注册设置 schema（前端统一渲染，**禁 Mod 注入 HTML/JS**）。
:18    fn register_settings(&mut self, spec: ModSettingsSpec) -> Result<(), ModError>;
:20    /// 订阅一个事件主题（返回可取消 id）。
:21    fn subscribe(&mut self, topic: ModEventTopic) -> Result<SubscriptionId, ModError>;
:23    /// 取消订阅。
:24    fn unsubscribe(&mut self, id: SubscriptionId) -> Result<(), ModError>;

```
三个可核点：
1. **25 行、三个方法、每个方法都带 `-> Result<_, ModError>`**
   => **没有一条不返回 Result 的路径** => 与 B0453 核的「解析不了时不猜」同族：
   **注册表的所有能力都要求调用方处理失败**
2. **每个方法的签名里都带一句后果**
   - `register_settings`：「前端统一渲染，**禁 Mod 注入 HTML/JS**」
   - `subscribe`：「（**返回可取消 id**）」
   - `unsubscribe`：有 id 所以可撤
   => **三条都是「这条能力能做什么 / 不能做什么」** => 与 B0500「一条禁令要带后果」**同族**
3. **`SubscriptionId(pub u64)` 是个 newtype**（不是裸 u64）
   => **cancel 用的 id 与别的 u64 不同类型** => **传错编译不过**
   => 与 B0550 核的 `config_path: String` **同族**（**类型承载语义**）
   而 `:9` 的 `pub u64` 是**公开字段** => 任何 Mod 能自己造一个 id 传给 `unsubscribe`
   => **未核**：id 是否按 mod 分区（A Mod 的 id 能否撤掉 B Mod 的订阅）
   => 记为待核（**若能跨 Mod 撤订阅、那就是一个越权面**）
