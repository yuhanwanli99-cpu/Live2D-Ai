## 三个可核点

1. **格 ②**。判据 1：B0730 按 3x2 数 json，**漏了**这一类——
   它是**协议文档**（.md），**不是**数据文件**（.json/.yaml）。
   判据 2（可复用）：分类的**第一刀**是「**它是数据**还是**它是文档**」。
   差别的量度：json 的消费者是**代码**打开它；.md 的消费者是**人**读它。
   判据 3（本批落点）：协议文档的「消费者」**只能**是**人**
   => 它的**格子**由「**有没有测试**在**检查**它**」**决定**。
   判据 4（可复用）：**数据型**的格子由「消费 + 测试」**两个**数决定；
   **文档型**的格子**只**由「**测试**」决定**（消费恒 0，但**那不叫**缺陷）。
   承 M11h（「单源」分**数据型**/**文档型**）—— M11h 说**两种**，
   本批说**了它们**的**格子判据不同**。

2. **格 ② 的处置在这里变了**。B0728/B0730 说 ② 处置=「加消费者**或**加测试」。
   **本例**：测试**已**在 => 处置**只剩**「加消费者」**一条**路，
   而**加消费者**意味着**改产品**（协议要**被**渲染面**遵守**）。
   判据 1：**处置的条数**取决于**格子**里**哪一项**已经**满足**。
   差别的量度：① 0 条 ② **1** 条 ④ **3** 条。
   判据 2（本批落点）：**报状态**要**同时**报「**处置有几条路**」——
   它是**格子**的**函数**，**不是**格子**的**标签**。
   判据 3（可复用）：④ 的**三条路**里**最贵的**是「**删**」——
   因为**它**要**确认**没有**未来**消费者**（**要**看**计划**）。
   判据 4：② 的**一条路**（加消费者）**要**改**代码**，
   它的**成本**通常**高于**④ 的「加测试」**那条**。
   判据 5（本批的结论）：「**修一个格子**」的**成本**不是**格子**的**一个**函数**，
   它是**（格子 × 哪一项已满足 × 改哪一侧）**的**函数**。
   承 B0709 §4「从**类型**能推出**接口**、**推不出**能力**」的**同源**。
   承 M19（**判据**要**有**适用**边界**）的**追加**。

3. **修正 B0728**：它把 persona.yaml 与 slop_rules.json **并列为**「②」**—— 错**。
   slop_rules.json **测试也**是 0（B0719 核过 tests/ 里 grep slop_rules = 0 命中）
   => 它是 **④**，处置 3 条；persona.yaml 是 **②**，处置 **1** 条
   （**且**它**是**「有意的 ②**」，B0729 核过 root-py-tests 专门跑它）。
   判据 1（可复用）：**每个**实例**都**要**带**它**的**处置条数**，
   否则「②」这个**标签**在**不同**文件**上**含义**不同**。
   判据 2（可复用）：「**相邻格**」**容易**被**合并**报**——
   因为**它们**的**处置**差一条**。而**这**正是**它们**该**被**分开**报**的**理由**。
   判据 3（本批落点）：「**处置路数**」**应该**成为**格子**的**主键**，
   **而不是**「**格子编号**」**成为**报告**的**主键**。
   判据 4（可复用）：「**有**几条路**」**可以**机检**，
   「**走**哪条**」**要**人**判**。
   判据 5（收束）：判据 ⑥ 是「**格子**」而判据 ⑰ 是「**最弱**形态**」—— **两者都**要**写**。
   差别的量度：**19 批**里**只有本批**写出**了**「最弱**形态**」**这**一**层**。
   判据 6（本批真正落点）：「**最弱**形态**」**应当**在**提出**分类**的**那一批**就**写出**——
   而**不是**在**第 19 批**才**想起来**。B0728 提 ② 时**没**写它，**那一漏**到本批才补。
   判据 7（可复用）：**每**一个**新**分类**都**要**带**「**它的**最弱**形态**」**一**行**。
   判据 8（收束整条线）：「**最弱**形态**」**这一行**本身**就是**「**零命中**」的**正当**用法**——
   而**它**前提**是**「**两侧**都**排过**」。承 M02 + M18 + M11j 的**完整**链条**。
   判据 9：**「**零命中**」可**不**可信**是**一个**可计算**的**问题**——
   它**取决于**你**排过**几**层**。差别的量度：B0685 排了 **0 层** => 被撤回；
   本批排了 **2 层**（写法 + 两侧规则）=> 可信。
   判据 10（收束）：「**排**几层**」**取决于**被搜**的**东西**是**不是**「**惯例**」**。
   差别的量度：① **数据文件** => 0 层**就可能**够 ② **函数调用** => 写法 + 多行 use **才**够
   ③ **标识符** => **要**排**「**路径**是**否**是**变量**」**（B0730）。
   判据 11（最终落点）：「**排**几层**」本身**是**一个**要**报**的**数字**——
