## B0558 · diag-stale.sh 的 2/3/4 节（B0603 只读了头 8 行）
```
echo "===== 2. 本地二进制构建时间 ====="
ls -la target/debug/live2d-ai-desktop 2>/dev/null | awk '{print $6,$7,$8,$NF}'
echo "===== 3. WASM dist 构建时间与 hash ====="
ls -la crates/l2d-wasm-demo/dist/*_bg.wasm | awk '{print $6,$7,$8,$NF}'
W=$(ls crates/l2d-wasm-demo/dist/ | grep '_bg.wasm$' | sed 's/.*-\([a-f0-9]*\)_bg.wasm/\1/')
echo "hash: $W"
echo "===== 4. 服务端实际返回（启动 3 秒探针） ====="
pkill -f 'live2d-ai-desktop --web' 2>/dev/null; sleep 0.5
LIVE2D_AI_WS_AUDIO=1 ./target/debug/live2d-ai-desktop --web --http-port 18999 ...
```
三个可核点：
1. **三个「东西的时间/hash」并排摆出**（二进制构建时间 · WASM 构建时间 · WASM 文件名里的 hash）
   => 与 B0600 核的「把产物在不在当场摊开」**同族**
2. **WASM 文件名里带 hash**、脚本用 `sed` 把它抠出来
   => **文件名即版本** => 「你看到的到底是哪一版」不靠猜、靠文件名
   => 与 B0600 核的「测试基线 407 → 421 当契约」**同一思路**（**把版本钉在一个可读的地方**）
3. **它自己起一个服务**（`--http-port 18999`、先 `pkill`）=> 与 `ignite.sh:199` /
   `run-web.sh` 的 `pkill ... || true` + `sleep 0.5` **逐字重复**
   => 那两处的 `|| true` 是「杀不掉也继续」；**这里没有 `|| true`**（`pkill` 返回 1 时
   脚本继续，因为不是 `set -e`）=> **三处同一动作、三种写法**
