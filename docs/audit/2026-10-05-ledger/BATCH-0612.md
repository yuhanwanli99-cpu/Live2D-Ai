## 逐行
```
:47  DO_CHECK=0
:51    --check) DO_CHECK=1 ;;
:54    -h|--help) sed -n "2,17p" "$0"; exit 0 ;;      # ⭐ -h 打印自己的用法段
:65  if [ "$DO_CHECK" = "1" ]; then                      # ⭐ 体检是一个 if 块

:115  echo "[error] 需要 python3 读取 live2d-ai.toml"; exit 1
```

## 五个可核点
1. ⭐⭐⭐⭐⭐⭐⭐⭐ **⇒ `:65` 的 `if [ "$DO_CHECK" = "1" ]` 把体检**整块包住**、`:108` 在块尾 `exit "$fail"`**
   ⇒⇒ **⇒ 体检之后**不会继续走到启动** ⇒⇒ **⇒ 与 B0607 核的「`--check` 不自启服务」**是同一件事的两个保证**（一句提示 + 一个结构）⇒⇒⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
2. ⭐⭐⭐⭐⭐⭐ **⇒ 而退出码是**失败计数本身**（`exit "$fail"`、不是 `exit 0/1`）**
   ⇒⇒ **⇒ 与 B0607 核的「PASS/FAIL/SKIP **表**」**同一套**：**「几条没过」本身就是一个数** ⇒⇒⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
3. ⭐⭐⭐⭐ **⇒ 而 `-h|--help` 用 `sed -n "2,17p' "$0"` 打印**自己第 2–17 行**当用法**
   ⇒⇒ **⇒ 与 B0603/B0607 核的「用法写在头注」**同族、而**这里更进一步：用法是**被读出来**的、不必维护第二份** ⇒⇒⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
4. ⭐⭐⭐⭐ **⇒ 而 `:115` 的缺 python3 处理**也是 `exit 1` + 一句 `[error]`** ⇒⇒ **⇒ 与 B0571「每个失败形态都有一句话」**同族** ⇒⇒⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
5. ⭐⭐⭐ **⇒ 而「`live2d-ai.toml` 由 `python3` 读」这一条** ⇒⇒ **⇒ 与 B0417 核的「用原生可测的纯函数」（`stage_bg.rs` / `stage_css.rs` 是同一个教训的反面）**是**不同**的取舍**
   ⇒⇒ **⇒ 即：点火脚本里用 `python3` 读 toml（**脚本不属于 wasm、不能编译进测试**）** ⇒⇒ **这个取舍与 B0417 那条并不矛盾** ⇒⇒⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐

## 结论
- **B0611 的待核结清**：`DO_CHECK=1` **以 `exit "$fail"` 落地**、**不继续启动**、**退出码 = 失败条数**。
