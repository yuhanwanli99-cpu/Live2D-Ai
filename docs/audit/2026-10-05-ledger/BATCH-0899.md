# BATCH-0899 · 「有覆盖+有文件」**那 27 个**的「覆盖」**是假的** —— `B0552-0556.md` **正文**只提 **B0554 B0556 B0648 B0649**，**不**提 **0553**

命令: wc -l 两个文件; grep -n '0553' B0552-0556.md; grep -o 'B0[0-9]{3}' B0552-0556.md|sort -u
实数: B0553.md **40** 行 / B0552-0556.md **20** 行；grep '0553' **= 0 命中**
**正文**提到的批号 = **B0554 B0556 B0648 B0649**（**4** 个，**不**含 0553）
其余 9 个范围名文件的**首行**都是 `# BATCH-XXXX-YYYY 落盘…`（**文件**名**即**首行**）

判据 1(本批真正落点): ★ 「覆盖」**是假的** —— **文件名**的**范围** **≠** **正文**覆盖**的**批号
  => B0552-0556.md **正文**不提 0553 => 0553 **那**一批 **只有** B0553.md **一个**入口**。
判据 2(真正产物之二): ★ 「**有**覆盖 **+** **有**文件」**这**个**桶** **整个** **塌掉**了** ——
  => 27 **个**批号**其实**都是**单入口**；**真正**的双入口**可能** **是** 0。
  => 「重复」桶 **是** 一个**由**文件名**造出来**的**假象**（承 B0873「多对多」的**本体**就是文件名**）。
判据 3(可核): 0552-0556 **正文**提到 **B0554 B0556**（**在**范围**内**）**与** **B0648 B0649**（**在**范围**外**！）**
  => 它**还**提到**范围外**的批号 => 「范围」**连**「该文件谈的批」都**不是**。
判据 4(收束): ★ **文件名** **≠** **内容**的**索引** —— 「B0552-0556」**只**是**一个**命名**习惯**
  => 「覆盖」**要**读**正文**才**能**确定** => **=>** 那 **57** 个「无单批文件**的**被覆盖批」**也**要**逐个**读**。
判据 5: **9** 个范围名文件**的**首行**都是** `# BATCH-XXXX-YYYY 落盘…` **=>** **命名** **一致**
  => **但** **一致**的**命名** **不**保证**一致**的**内容**（0552-0556 **就是**反例**）。
判据 6(本批真正产物之三): ★ **「**索引**」**与「**命名**」**必须**分开** ——
  => 本审计**一直**把**文件名**当**索引**用**（B0873/B0876/B0877 **的**全部**计算**都**建立**在**它**上面**）
  => **=>** **=>** **那** 10 **批**的**多对多**结论**要** **降级**为**「**命名**现象**」**。
判据 7(可执行): **逐个**读 **10** 个范围名文件**的**正文**，数**各自**提到**几个**批号** => **成本 10 条 grep**。
判据 8(承 B0898 判据 4): B0898 **问**「那 27 批**的**两个**入口**内容**一致**吗**」** —— **=>** 本批答：**不**存在**第二个**入口**。
