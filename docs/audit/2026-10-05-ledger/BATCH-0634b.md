## 三个可核点
1. **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ 「有没有自测」的答案是**没有** ——
   `stripCommentsAndStrings` 在 `design_tokens_test.dart` 里**只有 1 个定义 + 1 个自身调用**，
   没有任何 `test(...)` 以它为对象
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 后果（三层，逐层加重）**：
   - 它是 **11+ 个门禁断言**的输入预处理
   - 它是 **8 份拷贝**（B0632c）里每一份的实现
   - 它的正确性**没有任何一条断言直接保护** ⇒⇒
   **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒ ⇒⇒⇒⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 判据（本批最值钱）：
   **一个函数被 N 处依赖时，它的测试价值按 N 增长，而不是按它的行数**
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 42 行的手写词法器 + 11 个依赖 + 0 自测
   = 一个「改错了要跑 8 个测试文件才发现」的组件**
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 严重度候选 P2**（本批**不立** ——
   需先核「它被自身所在测试的其它断言间接覆盖多少」）
2. **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ 而**能给它写自测的材料本仓已有**：
   B0631b 核的四种结构（普通字符 / 行注释 / 块注释 / 字符串·单双三引号·转义）
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 判据（可复用，可直接落地的形状）：
   **词法器的自测不需要复杂用例，四个断言就够** ——
   ⇒⇒ ① `'a' // b` ⇒ 结果里**不含** `b`
   ⇒⇒ ② `/* c */ d` ⇒ **不含** `c`
   ⇒⇒ ③ `'x'` ⇒ **含** `'S'`（占位版）/ **不含任何字符**（无占位版）⇒ **这两条正是本审计在 B0633b 核到的 7/1 分歧**
   ⇒⇒ ④ `'''a'''` 与 `'a\'b'` ⇒ 各自的边界
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 判据（第二句）：
   **B0633b 发现的「7 份删占位、1 份留占位」正好是这两版自测的第 ③ 条**
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 也就是说：
   只要两版都补上这条断言，那处分歧就会**立刻变成一个被命名的问题**（要么都写 `S`、要么都不写）**
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒ ⇒⇒⇒⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒ ⇒⇒⇒⇒⇒⇒⇒ ⇒ ⇒ 判据：
   **「同一份实现的 N 个变体」最有效的统一手段不是写规范，是给每版加同一条自测。**
