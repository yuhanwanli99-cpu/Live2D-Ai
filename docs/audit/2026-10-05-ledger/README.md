都以它的 F-ID 为指路牌。于是本轮裁决：**并入 `docs/audit/`，入库**。理由三条：

1. 备份问题只能在仓库里解决（此前删掉工作树 = 台账消失）；

3. 它是纯文本、可 grep —— 下一轮做债时不必再去解压归档。
