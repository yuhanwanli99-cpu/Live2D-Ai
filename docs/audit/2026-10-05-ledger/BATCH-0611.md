## 六个可核点
1. ⭐⭐⭐⭐⭐⭐⭐ **⇒ 判据是**两个值同时成立**：`root_code = 302` **且** `root_loc = /app/`**（`:73` 的 `&&`）
   ⇒⇒ **⇒ 与 B0589 核的「`applied = true` 无条件」**不同族、而与 B0571 核的「一个判据两处各判」**同族**：

2. ⭐⭐⭐⭐⭐ **⇒ 而 `[ok]` 与 `[FAIL]` 两行都把**实测值**打出来**（`:76` 的「实得 ${root_code:-无响应}」）
   ⇒⇒ **⇒ 与 B0607 核的「PASS/FAIL/SKIP 表」**同族、而**这里连「没响应」都有形态** ⇒⇒⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
   ⇒⇒ **⇒ 这与 B0607 核的「只对**已经在跑**的服务打 loopback」**完全同一条** ⇒⇒ **⇒ 三个脚本共用一个前提** ⇒⇒⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
4. ⭐⭐⭐⭐⭐⭐ **⇒ 第三条是「`index.html` 与 `main.dart.js` **不含** `gstatic.com/flutter-c…`」**（`:89` 遍历两个文件、`:94` 逐个 grep）
   ⇒⇒ **⇒ 这就是 AGENTS 记的**「断网红线」自动化** ⇒⇒⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
