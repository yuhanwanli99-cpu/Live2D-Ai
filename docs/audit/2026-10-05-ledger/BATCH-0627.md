## 五个可核点
1. => 「**全仓库唯一一处**」⇒ 合并的**目标**写在第一行
   => 与 B0499 核的「判据收敛到一处」**同族**（而 B0626 记的观察是**另一半**：两个控件并存）
   => ⇒⇒⇒⇒ 也就是说：**提示**收敛了、**强调档**也收敛了，
   **而 B0626 看到的是「同一个分区里两个控件」** ⇒⇒ **⇒⇒⇒⇒ 那两个不矛盾**：
   **一个说「提示归一处」、另一个说「提示有两种能力」** ⇒⇒ **⇒⇒⇒⇒**
2. => 表格**三行、每行带文件与行号**（`ui/field_row.dart:95` / `dev_tools_section.dart:165`）
   => 与 B0609 核的「三处引用、每处带行号」**同族**
   => 而「当时的样子」这一列**给的是形状不是位置**（`dangerSurface` + `dangerBorder` + 图标）
3. => 「一个 Unicode 字符冒充图标」⇒ **否掉一种做法、并且说清它错在哪**
   => 与 B0407 核的「断网豆腐块」**同族**（**说清坏在哪、而不只是「不要」**）
4. => 而「⚠」这个字符**本身**正是 AGENTS 记的那条约束的同类
   （「界面文案里不得出现子集外的字符」· 实测抓到 `▍` U+258D 与 `⌘` U+2318）
   => ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒
   ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒
   ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒
   ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒⇒
   => ⇒ **「用字符冒充图标」在两条纪律下都有代价**：一条是 a11y/视觉、一条是**字体子集**
   ⇒⇒ **⇒⇒⇒⇒** **未核**：`⚠`（U+26A0）**在不在**当前字体子集里（**`test/font_subset_test.dart` 管这个**）
