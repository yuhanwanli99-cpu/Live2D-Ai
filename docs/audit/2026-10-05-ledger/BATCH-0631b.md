## 四个可核点
1. **⭐⭐⭐⭐⭐ ⇒⇒⇒⇒ `:37 out.write('S')` —— 字符串不是被**删掉**，而是被**替换成单个 `S`**
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 判据（本批最值钱，可复用）：
   **「剥离」类函数要写清「留下什么占位」** ——
   ⇒⇒ ⇒⇒ ⇒ 全删会让「`'s0'` 里的 `s0` 消失」与「源码里的 `s0` 消失」**无法区分**
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒ 换成 `S` 之后，
   「引号内出现过内容」仍占一个位置，而内容本身不参与匹配** ⇒⇒ ⇒⇒ ⇒
   **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒ 承 B0598 核的 `canRequestFocus` / `findsNothing`
   那条「否定式断言」**同族** ——
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒ 判据（更一般的表述）：
   **过滤器要区分「被过滤的东西原来在不在」—— 用一个固定占位符而不是删除，
   就能保留「这里曾经有过东西」这个信息。**
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒⇒ 建议（P3，不立）：
   函数名 `stripCommentsAndStrings` 只说了「剥离」，
   没���「字符串变成 S」** —— 改用 `stripToSentinel` 或在头注补一句。
2. **⭐⭐⭐⭐⭐ ⇒⇒⇒⇒ 而它是一个**手写的、逐字符的 Dart 词法器**，
   认得 **4 类东西**：普通字符 / 行注释 / 块注释 / 字符串（**单引号·双引号·三引号**·转义）
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 判据（本批第二个可提炼的）：
   **凡是「扫源码做检查」的测试，都必须自己处理注释与字符串，
   否则注释里写一个令牌名就会让检查误判** ⇒⇒ ⇒⇒ ⇒
   **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒ 这与 B0579 核的
   `check_public_secrets.py` 的 `SKIP_SUFFIXES` **不同层** ——
   那条是「哪些**文件**不扫」，这条是「文件**里面**哪些内容不算代码」⇒⇒ ⇒⇒ ⇒
   **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒ 判据：源码扫描测试的两层过滤
   （文件级 / 内容级）要分别处理，缺一层就出假阳性或假阴性**
3. **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ 而 `:24-26` 的三引号识别是**「连续三个同样的引号」**
   （`src[i+1] == c && src[i+2] == c`）⇒⇒
   **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 判据（细节）：Dart 允许 `'''` 与 `"""` 两种三引号，
   也允许 `'a"b'` 这种内含另一类引号的串** ⇒⇒ ⇒⇒ ⇒
   **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒ 判据：**注释里说「处理了三引号」时要说明是哪一种** ——
   本例是 `c + c + c`（同类三连），**不是**任意三个引号 ⇒⇒ ⇒⇒ ⇒
   **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒ ⇒ 判据（更普遍）：**处理「引号配对」的代码，
   其正确性依赖语言的具体规则**；只写「支持三引号」不足以让后来人判断对不对。
4. **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ 而这个函数**没有头注**（`:18` 直接是 `String strip…`）
   ⇒⇒ **⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒⇒ 判据（承 B0629 第 ② 点）：
   **一个函数是别的测试的依赖时（被 `import`），它最该有头注** ——
   ⇒⇒ ⇒⇒ ⇒ **因为读它的人常常是通过「另一个文件」到达它的**
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒ 承 B0630b 第 ④ 点
   「两个测试共用一个工具函数时它不该住在其中之一」** ——
   ⇒⇒ ⇒⇒ ⇒ **本例的处置恰好相反：它住在其中一个里，而那个文件自己有 400+ 行的业务内容**
   ⇒⇒ ⇒⇒ ⇒ **⇒⇒⇒⇒ ⇒⇒ ⇒⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒ ⇒⇒⇒⇒ ⇒ ⇒ 两处合看：
   **该函数（工具）既没有独立成文件、也没有头注** ⇒ **P3 候选，不立**（两处都很轻）。
