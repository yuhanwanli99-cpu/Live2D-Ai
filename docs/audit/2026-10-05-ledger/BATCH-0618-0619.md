## B0618 · nightly.yml「缺配置明确跳过」的形状
```
:7   # …LIVE2D_AI_VERIFY_BASE_URL 时跑；缺配置明确跳过，不伪造绿灯
:68  # 所以：配了仓库变量 `LIVE2D_AI_VERIFY_BASE_URL`（**Variables，不是 Secrets**）
:74    if: ${{ vars.LIVE2D_AI_VERIFY_BASE_URL != '' }}
:91          LIVE2D_AI_BASE: ${{ vars.LIVE2D_AI_VERIFY_BASE_URL }}
```
三个可核点：
1. 判据是 job 上的一个 if:，且是 != ''（空串）而不是 == 'true'
   => 与 B0453 同判据：不能用「某个值有语义」当缺失（空串不是有意义的 base_url）。
2. 读的是 vars. 而不是 secrets. —— 而 :68 注释**点名了这个区别**（Variables，不是 Secrets）
   => 一个 URL 不是密钥，所以放 Variables 是对的；注释把「为什么不是 Secrets」写下来了。
3. 同一变量在 :74 判存在、在 :91 传值 => **判据与取值同源**，
   与 B0573 核的「显示的值与将要提交的值走同一个判据」同族（判据只写一次、值只读一次）。
