## 0. 标签与前提

**每个条目只带一个标签**（三选一）：

| 标签 | 含义 | 谁来勾 |
|---|---|---|
| **自动化已覆盖** | 有可失败断言守住该行为；人只需**抽查**一眼，不必逐项走 | 任何人（README 级复核） |
| **只能人工** | 断言只能守到结构/行为，观感与读屏体验**只能人判** | 维护者（Windows 浏览器） |
| **需真服务或 Windows 侧** | 需要活 LLM/TTS 端点、Live2D 模型、或 Windows 浏览器栈 | 维护者（Win + 活服务） |

**环境前提（缺任一条 ⇒ 相关项一律记「未验」，不许改判成「通过」）**：

- **活服务**：`./scripts/ignite.sh`（默认 `127.0.0.1:18080`）在跑；另开终端 `./scripts/ignite.sh --check` 四项全 ok。
- **LLM 端点**：`live2d-ai.toml` 的 `[llm]` 指向可用端点，`.env` 里有 key（`GET /api/v1/env` 只回键名与是否已设置）。
- **TTS 端点**：`[tts]` 段指向可用端点（本机默认 `127.0.0.1:8080`，**默认无服务**）。

  ⇒ 没有模型时**一切舞台类项都不成立**，直接记「未验（缺模型）」。
- **浏览器**：Windows 侧 Chrome / Edge（`http://127.0.0.1:18080/app/`）。**不要在 WSL 里点**，也不要在 Windows 侧编产物。

> **四栏全项都是「需真服务或 Windows 侧」**：本仓不捆绑 Live2D 模型、本机默认无 TTS 端点
> （见 `docs/releases/v0.2.0-rc.6.md` §5 与 `HANDOFF-2026-09-27-stageB-plan-and-status.md` §2）。
> 断言只守住"帧/接线/配置面"，**观感与音频只能人工**。
> 资产接触点全集与守护断言对照见 `docs/architecture/frontend-asset-inventory.md`（A1–A8 + 19 条断言）。

- [ ] **3.1 动作 / 表情**：发一条消息 → 皮套有反应（不是全程不动）
  - 期望：回复期间有按句的动作/表情；中性轮**不该**留着上一句的表情（撤销哨兵生效）。
  - 自动化守到：`test/asset_guard_preset_dispatch_test.dart`（`applyPreset` 函数体必须转发、缺 field 时**只发旧四键**）、
    `test/asset_guard_director_cue_test.dart`（`main.dart` 必须**调用** `_applyDirectorCueForSeq`，不是只定义）、
    `test/action_cue_test.dart`（`none` → 恰好一次撤销 / 同 seq 只应用一次）。
  - 标签：**需真服务或 Windows 侧**

- [ ] **3.2 语音**：出声、**一句一单元**（不做句中切分）、音量/静音与口型正交
  - 期望：整句连续播放，不出现"断断续续"；改音量/按静音**不影响口型**。
  - 自动化守到：`test/asset_guard_tts_config_test.dart`（5 条配置面 widget 断言）、
    `test/settings_controller_test.dart`（PATCH 只含 `tts.voice` 等）。
    **音频本体与站点级静音路径无 Flutter 自动化**（Rust 侧另有回归）。
  - 标签：**需真服务或 Windows 侧**

- [ ] **3.3 口型**：说话时嘴动，且与**音频播放时钟**同拍
  - 期望：无"音先到、嘴后动"的明显错位；句首/句末边界不漂。
  - 自动化守到：`test/stage_clock_test.dart`（30 ms 节拍 + `main.dart` 转发接线）、
    `test/render_events_test.dart`（事件级 ack 解析 + ack → 快照 `presetStatusUpdateFor`，`:275` 一带）。
  - 标签：**需真服务或 Windows 侧**

- [ ] **3.4 导演可观测四栏（`dev_mode=true` 才渲染）**
  - 怎么验：设置 → 开发工具（`dev_mode` 打开）→ 看四栏：**A 决策参数** / **B 事件流** / **C 传参对照** / **D 送 TTS 文本**。
  - 期望：四栏**都有数据**（A 有 emotion/intent/preset_id，B 有帧流水，C 左右两列可对照，D 左列 = 已收 `text_delta`）；
    `dev_mode=false` 时**整块不在语义树**里；缓冲**不落盘**（`localStorage` / `SharedPreferences` 里找不到观测缓冲）。
  - 自动化守到：`test/director_observer_test.dart`（标识符交集：禁止持久化标识符）、`test/director_panel_test.dart`。
  - 前提：需 `director` Mod 启用（缺省**停用**）+ 至少一条真实回复；无 TTS 端点时 D 栏仍应有数据（它读 `text_delta` 与日志）。
  - 标签：**需真服务或 Windows 侧**

## 4. 组 4 · 离线优先（`--no-web-resources-cdn` + 自托管字体）

- [ ] **4.1 断网刷新 `/app/` 不白屏**
  - 怎么验：先正常打开一次（预热缓存）→ DevTools → Network → 勾 **Offline**（或直接断网卡）→ **F5 硬刷新**（可再勾 Disable cache）。
  - 期望：界面照常起来；CanvasKit 走本地 `build/web/canvaskit/`；中文字**不是豆腐块**。
  - 前提：产物是**带** `--no-web-resources-cdn` 构建的（见 4.3）；否则本项必然白屏，别把它记成 bug。
  - 标签：**只能人工**。
- [ ] **4.2 全程**没有** `fonts.gstatic.com` / `gstatic.com/flutter-canvaskit` 请求**
  - **DevTools 过滤关键词**（Network 面板左上过滤框，逐个粘）：
    `gstatic` · `fonts.gstatic` · `canvaskit` · `flutter-canvaskit`
    （也可在 Console 里 `performance.getEntriesByType('resource').map(e=>e.name).filter(n=>/gstatic/.test(n))`，
    期望返回**空数组**）。
  - 期望：三个关键词命中 **0** 条记录；刷新、切主题、流式回复、进设置面板**全程都查一次**（字体是按需拉的，只在有缺字时才炸）。
  - 自动化守到：`scripts/ignite.sh --check`（`index.html` / `main.dart.js` 断言不含 `gstatic.com/flutter-canvaskit`；
    实现见 `scripts/ignite.sh:185`）、`test/font_subset_test.dart`（源码字面量 vs 子集范围）、
    `test/font_runtime_subset_test.dart`（**运行态**文本来源：模型输出/后端文案/Mod 运行态值，含 `crates/*/src` 文案）。
  - 标签：**自动化已覆盖**（产物静态扫描 + 运行态来源门禁）；**但 DevTools 实看仍建议做一次**（抓"门禁没覆盖到的新来源"）。
- [ ] **4.3 产物新鲜**（改过前端就必须重建；否则以上全是假绿灯）
  - 怎么验：比较 `shell/flutter/build/web/main.dart.js` 与 `shell/flutter/lib/` 最新 `.dart` 的 mtime；跑一次
    `flutter build web --release --base-href /app/ --no-web-resources-cdn`（**`--no-web-resources-cdn` 不是可选项**）。
  - 期望：产物比源码新；构建后 `grep -rl 'gstatic.com/flutter-canvaskit' shell/flutter/build/web/` 命中 0。
  - 标签：**自动化已覆盖**（`ignite.sh` 的 mtime/产物对比 + 上条 grep）。
  - 注意：改 `crates/l2d-wasm-demo/**` 要 `trunk build`（`dist/` 被 gitignore），**不是** flutter build。
