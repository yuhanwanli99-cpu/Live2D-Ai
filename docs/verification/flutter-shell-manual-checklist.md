# Flutter 前端人工自测清单（`flutter test` 覆盖不到的部分）

> 来源：`docs/design/web-ui-spec-v3.md` §11.5。
> **为什么这些必须人工**：它们要么依赖真实浏览器（WebAudio autoplay、
> CanvasKit、iframe 平台视图），要么依赖真实网络/服务端状态，
> 都不是 `flutter test`（VM + 假异步）能表达的。
>
> 前置：
> ```bash
> cd shell/flutter && flutter build web --release --base-href /app/ --no-web-resources-cdn
> # 服务端（默认出声）
> set -a && . ./.env && set +a && ./target/debug/live2d-ai-desktop --web --http-port 18080
> ```
> 打开 `http://127.0.0.1:18080/app/`。

## 1. 仅用键盘发一条消息，确认**有声音**（钉子 9）

**为什么**：WebAudio 需要一次用户手势才能 `resume()`。只挂指针事件时，
纯键盘用户会「消息发得出去、嘴在动、但没有声音」，而界面不解释。

步骤：
1. 不要碰鼠标。按 `Tab` 若干次把焦点移到输入框（应看到 1 px 焦点环）。
2. 输入「说两句话」（用键盘）。
3. 按 `Ctrl + Enter`（macOS：`⌘ + Enter`）。

期望：
- [ ] 消息发出，助手气泡出现并流式上屏
- [ ] **能听到声音**（这是本项唯一要验证的事）
- [ ] 音频条上**没有**「点击任意位置或按任意键以启用声音」这行提示
- [ ] 口型跟着动

反例（若没听到声音）：音频条应显式显示那行提示 + 一个「启用声音」按钮——
**这才是合格的表现**（失败被显式化，而不是静默无声）。

## 2. 断网打开页面：中文正常、无白屏（C1）

**为什么**：CanvasKit 缺 `--no-web-resources-cdn` 会走 Google CDN；中文字体不自托管
会走 `fonts.gstatic.com`。**两者都在有网时完全看不出来**。

步骤：
1. 断网（或断掉对 `www.gstatic.com` / `fonts.gstatic.com` 的可达性）。
2. 打开页面（可先强刷清缓存）。

期望：
- [ ] 不白屏，界面正常渲染
- [ ] 中文**不是豆腐块**（问一句、看回复）
- [ ] DevTools Network 里没有指向 `gstatic.com` 的请求

## 3. 服务端静音：听不到、口型照动、徽标出现

**为什么**：验证「静音」与「口型」是两个正交轴。

前置：以 `LIVE2D_AI_MUTE_AUDIO=1` 启动服务端。

期望：
- [ ] 完全听不到声音
- [ ] **口型照常动**（服务端下发零 PCM + 真实 `volume`）
- [ ] 音频条出现「服务端静音中（LIVE2D_AI_MUTE_AUDIO=1）」只读徽标
- [ ] 本机静音开关**仍可用**、且与上面那个徽标是**两个不同的东西**

## 4. 打开 `dev_mode` → 日志区从 403 变为可读

**为什么**：日志端点确实会回 403 `dev_mode_required`。把用户态当异常渲染
是最常见的 UX 错误（钉子 14）。

> 2026-09-11 修：这个开关此前**在界面上打不开** —— 唯一能开它的 Toggle
> 在「开发模式」分区里，而那个分区在 dev_mode 关时被隐藏（死循环）。
> 现在分区**恒在**，路径是 设置 → 开发模式 → 开发者模式 → 保存。

期望：
- [ ] `dev_mode` 关：诊断分区日志区写「日志需要先打开「开发模式」」，
      **不是**红色错误横幅
- [ ] 设置 → 「开发模式」分区**一定看得见**（不再随 dev_mode 隐藏）
- [ ] 在那里打开并保存后：诊断分区日志**读得出来**（不再是 403）
- [ ] 保存时**配置文件里的注释不许被抹掉**（这是 v0.5.1 修的数据损失：
      写回走 `toml_edit` 就地改值；改完 `grep -c '^#' live2d-ai.toml` 应不变）

## 5. 说话中按「停止」：音频**立即**停（钉子 13）

**为什么**：TTS 分片是 1 ms 级突发、时间轴最多排到 3 s 之后。
只靠「下一帧带新 epoch」触发打断的话，停止按钮等于失灵。

期望：
- [ ] 按下后声音**立刻**停（不是几百毫秒后）
- [ ] 状态胶囊短暂显示「已打断」后回落空闲

## 6. 说话中切换设置分区：**模型不重载**（钉子 4 的人工版）

**为什么**：舞台是 iframe，一旦离开 Widget 树就被销毁（模型重载、口型时间轴清零）。

期望：
- [ ] 打开设置 → 依次点过 8 个分区 → 舞台**始终在跑**（模型没闪、没重载）
- [ ] 拖动窗口宽度跨过 1280 / 900 两个断点 → 同样不重载
- [ ] 拖「模型缩放」滑杆时**同屏能看见舞台反应**

## 7. `--profile` 构建下测帧时间（P6）

```bash
cd shell/flutter
flutter build web --profile --base-href /app/ --no-web-resources-cdn
```

期望（对着 DevTools Performance 面板，说话中录 10 s）：
- [ ] 没有长时间的黄色/紫色长帧（> 50 ms）
- [ ] 拖动滑杆、滚动聊天列表时帧率稳定
- [ ] 舞台区域的重绘**不牵动**聊天列表（`RepaintBoundary` 生效）

## 8. reduced motion：开着时无持续动画

步骤：操作系统打开「减少动态效果」（Windows：设置 → 辅助功能 → 视觉效果 →
动画效果；或 DevTools → Rendering → Emulate CSS `prefers-reduced-motion: reduce`，
Flutter Web 引擎会把它读进 `AccessibilityFeatures`）。

期望：
- [ ] 「思考中」的呼吸光**不闪**（静态描边）
- [ ] 流式三点**不跑**
- [ ] 消息渐入等过渡明显变快或直接到位
- [ ] **没有**任何持续闪烁的元素

## 9. 角色卡导入（两条路）

期望：
- [ ] 导入一个 `.json` 酒馆卡 → 五项人设被填入，且列出「未映射字段」
- [ ] 导入一张内嵌角色的 `.png` → 同上
- [ ] 导入一个**不是**角色卡的文件 → 明确报错（不是静默什么都不做）
- [ ] 导入后**不自动保存**（要点「保存」），且保存前顶部有「未保存」Pill

## 17. 压在舞台上的控件**必须真的点得着**（`flutter test` 覆盖不到）

**为什么**：舞台是 `<iframe>` 平台视图。Flutter Web 的两张画布都是
`pointer-events: none`，真正接指针的是 iframe 这个 DOM 元素、且它在画布之上——
指针落在舞台区域会进 **iframe 自己的文档**，父页收不到。所以压在舞台上的 Flutter
控件默认是**「看得见、点不着、也滑不动」**，而 widget 测试（VM、没有 DOM）
**永远抓不到**。自动回归只到「有没有套 `StagePointerInterceptor`」为止
（`test/stage_pointer_interceptor_test.dart`）；**「套了以后真的点得着吗」只能人点**。

三种断点各来一遍（窗口宽度 ≥1280 / 900–1279 / <900）：
- [ ] 打开设置：面板上**每一条**都能点——分区 chip 能换区、滑杆能拖、输入框能输入
- [ ] 设置面板能**上下滚动**（滚轮停在面板上滚，不是滚了背景）
- [ ] `expanded` 内联侧板：点 ✕ 能关、Esc 能关、关掉再打开时**滚动位置还在**
      （2026-09-11：左侧 rail 已删，原来的「rail 上再点同一分区能收起」已无对象；
      侧板改成**折叠而不是卸载**，见前端加强计划 P1-1）
- [ ] `medium` / `compact`：点浮层里的「保存 / 放弃」有反应
- [ ] 舞台**右下角**「缩小 / 100% / 放大 / 复位」四键都点得动，读数跟着变
- [ ] 断线时（把后端停几秒）横幅上的「点此重试」点得着
- [ ] 渲染面失败时，错误覆盖层上的「重试」点得着
- [ ] **对照项**：舞台左侧空白区仍然能**拖动模型**——垫层只罩控件那一块，
      不许把整块舞台的交互一起吃掉（`sync.clickEnabled`）
- [ ] DevTools 里 `document.elementsFromPoint(x, y)` 在控件上返回
      `DIV`（`flt-platform-view`），**不是** `IFRAME`

**已知仍点不着的两处（不是回归）**：`showModalBottomSheet` 的模态障碍层
（「点空白关闭」）与拖拽把手——它们在 `builder` 子树之外，垫层罩不到；
取舍见 `lib/live2d/stage_pointer_interceptor.dart` 头注。
