# 0.6 线：Windows 原生 CosyVoice3 TTS（替换 MeloTTS）

> 状态：**活** · 立档 2026-11-10 · 覆盖 `0.6.0`。
> 这一篇是 0.6 大版本文档，单独计行数（不进 docs 合计 45,000）。
> 代码真源仍是 `docs/architecture/CURRENT.md` 与源码；本文记录范围、验收与边界。

## 1. 为什么有 0.6 线

0.4/0.5 线把「Windows 能跑、换皮套生效」做完了，但**本地 TTS 仍是 MeloTTS 垫片**：
Windows 上并没有可用的 MeloTTS 运行环境，实际出声退化成机械音，和「白模型待遇」同类问题。
0.6 线把 Windows 侧本地 TTS 换成 **CosyVoice3 zero-shot 复刻（大肥鱼 6 岁小奶音）**：
Python 3.10 + torch cu128 **原生 Windows** 常驻 HTTP sidecar，app 继续走既有 OpenAI 兼容
`[tts]` 端点；新增 Mod `cosyvoice3-tts` 负责探活/拉起/收尾。**运行期不依赖 WSL2。**

## 2. 组成

| 件 | 位置 | 说明 |
|---|---|---|
| sidecar | 用户目录（如 `D:\live2dai\tts-cosyvoice3`） | FastAPI + uvicorn，127.0.0.1:8011；`POST /v1/audio/speech`（pcm s16le 44.1k 单声道 / wav）、`GET /healthz`、`/v1/models`、`/v1/voices`；模型 fp32 加载一次 + spk 向量缓存 |
| Mod | 仓库 `live2d-ai-mod-cosyvoice3` | id `cosyvoice3-tts`、api_version 1；settings_spec：program/port/voice/auto_start/health_timeout_s；只探活/拉起/收尾，不写 `[tts]`、不推理、不下载权重 |
| 挂载 | 桌面工厂表 | 第 8 个 Mod；打包链 pin `1a05bf47e880ceebbf5899c0394b0827a0ce2cd6` |
| 脚本 | 包内 `tools/cosyvoice3/` | server.py、setup.ps1、start/stop/status.ps1+.cmd、requirements-win.txt、README.md、doctor/accept 工具；**不含权重/参考音色** |

## 3. 平台缺省（0.6.0 收口）

`DEFAULT_TTS_BASE_URL` / `DEFAULT_TTS_VOICE` 与 `apply_local_tts_defaults` 按平台分叉：

| 平台 | base_url | voice | 语义 |
|---|---|---|---|
| Windows | `http://127.0.0.1:8011/v1` | `dafeiyu` | 随包 CosyVoice3 sidecar（Windows 包不带 MeloTTS，8091 是死路径） |
| 非 Windows | `http://127.0.0.1:8091/v1` | `ZH` | 仓库自带 MeloTTS 垫片，2026-10-09 口径不变 |

出厂模板 `live2d-ai.toml.example` 的 `[tts]` 与 Windows 常量一致；用户在设置里保存「本地」TTS 不会再被打回 8091。
（`apply_local_tts_defaults` 仍清空 `model`，sidecar 不依赖该字段，不影响出声。）

## 5. Mod 生命周期（真机验收）

- 外部 sidecar 已就绪时 enable：**300 ms 内** `state=ready`、`pid=null`（不抢不杀、不重复拉起）。
- 未就绪时 enable：按 `program` 拉起（`start.cmd`），等 `/healthz` 到 `health_timeout_s`；失败进 Failed 并保留可读 `last_error`（`GET /api/v1/mods`）。
- 重复 enable 幂等；disable 只释放自己拉起的子进程，不碰外部服务。
- `GET /api/v1/mods/{id}/state` 在未启用/Failed 时仍返回 503（宿主既有行为，本轮不改宿主），错误文本从列表 `last_error` 读。

## 6. 文本前端缺失（如实）

pynini / wetext 无 Windows 轮子 → 不装。CosyVoice 前端日志会打 `no frontend is avaliable`；
中文标点/分句走非 wetext 分支，**数字/多音字不做 TN**。产品口径：app 侧送 TTS 前把数字写成汉字更稳；
后续可接 ttsfrd 资源或 coco-tn（未做）。
