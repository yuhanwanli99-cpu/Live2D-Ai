# 0.5 线：跨皮套换绑、出厂模型与皮肤支持

> 状态：**活** · 立档 2026-11-09 · 覆盖 `0.5.0` / `0.5.1` / `0.5.2`。
> 这一篇是 0.5 大版本文档，单独计行数（不进 docs 合计 45,000）。
> 代码真源仍是 `docs/architecture/CURRENT.md` 与源码；本文记录范围、验收与边界。

## 1. 为什么有 0.5 线

0.4 线解决「Windows 上能双击跑起来」。0.5 线解决「**换一张皮套，动作/口型/待机真的生效**」——
此前只有白模（bai）能吃到动作：所有参数写入都是**逐字精确匹配** 13 条标准名，bai 命中 11/13，
大写 `PARAM_*` 的第三方模型命中 **0/13**，连呼吸/眨眼/摆头一起静默失效。

## 2. 0.5.0 换绑（已落地，分支 bind/0.5.0，tag v0.5.0-rc.1…rc.6）

| 能力 | 实现 | 证据 |
|---|---|---|
| `ParamBinder` | 13 条 Cubism 标准语义名 → 模型实际参数 id；去 `Param_`/`PARAM_` 前缀、小写、剔 `_`；冲突按「精确标准名 > 大写 snake > 其它」稳定排序；解析不到返回 `None`，不 panic、不猜语义 | 真实 `epsilon_free.moc3`（30 参）13/13；bai 11/13 逐值不变 |
| Groups | 解析 model3 `Groups`：`LipSync` 名单优先，空则回落 `ParamMouthOpenY`；`EyeBlink` 名单进 idle | bai LipSync 空 → 回落路径逐值等价 |
| 每模型 `adapter.json` | `<model>/adapter.json`（gitignore、用户自持）：只允许 13 语义名 → 实际 id 的显式别名、`disable_channels`、`expressions` 名称映射（只存不播）；坏文件整份弃用并报 `source=degraded` | 无文件/坏 JSON/部分覆盖/全部覆盖/冲突记录 单测 |
| 可观测 | `loaded` 回执新增可选 `param_bind{source,missing,conflicts}`（旧宿主忽略） | swap_core 单测 |
| pose3 骨骼层 | model3 `Pose` + pose3.json `Groups [[{Id,Link}]]`；每组选第一个存在的 part 为激活，其余 opacity=0（修「两套手臂/腿同时显示」）；**只做静态选择，不做组内轮换** | 官方 haru 样本：2 组命中；headless 渲染「换掉 part 层像素哈希必变」 |
| 档位自适应 | 按贴图最大边选 4096/8192/16384 最小够用档；>16384 给类型化错误；wasm 侧档位不足给可读报错而非静默失败 | 大肥鱼 8192 贴图：默认档复现失败 → 自动档 5 张全装载 |

**不做**：exp3 / motion3 播放、手臂/手指/全身骨骼、动捕（项目既定边界）。

## 3. 0.5.1 出厂模型通用化（已落地，tag v0.5.1-rc.1）

- `ModelEntry.builtin`（serde default，旧 registry 兼容）+ `assets/models/seed.local.json`（gitignore）→ 本地模型与 bai 同待遇：出厂 seed、**不可删除**、列表徽章「出厂模型」、标题用 display_name（Flutter 去掉 bai 硬编码）。
- 删除保护按 `entry.builtin` 返回 `409 model_builtin`（保留 bai id 兜底）。

### 3.1 三个真机 bug（本轮修复）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| A | Windows 导入模型后 activate 200 但舞台不变、URL 变 `/models///?/D:/…`（404） | import 把 `\?\D:\…` verbatim 绝对路径写进 `model3_rel_path` | 纯函数剥 `\\?\`/UNC 前缀再求相对路径；失败 400；载入期对旧 registry 内存修复 |
| B | 官方 model3 的 `Layout`（`CenterX/Width` PascalCase）被整块忽略 → 尺寸错 | `LayoutBox::from_json` 只读小写键 | 两套键都认，小写优先 |
| C | 无 `Layout` 的新模型默认 1.0×1.0 → 竖长画布裁头 | 默认值 1.0 | 无 Layout 时用产品口径 0.56 / center_y −0.07 |

## 4. 皮肤支持（大肥鱼 / DeepSeek-chan）

- 模型事实：Cubism **5.0**，509 参数，5 张贴图（4096×8192 ×2、8192×8192、4096×4096、2048×2048），physics3 131 组；13 标准通道 **11/13**（与 bai 同缺两个 eye-smile）；`LipSync` 空、`ParamMouthOpenY` 存在。
- 许可：作者《使用须知》允许个人直播/创作/调参与二次创作，**禁止重新分发模型文件、禁止二次销售、禁止冒充作者**。因此：**模型不入 git、不随发布包对外分发**；本机用 `seed.local.json` + 本机模型库享受与 bai 同等待遇。
- 真机验收：真实 Chrome + WebGPU 完整出画、换模链 200 且 status 跟随、口型开/闭可见（回落 `ParamMouthOpenY`）、待机呼吸/眨眼在动、导入 URL 相对且 200、builtin=True、删除 409。
- 贴图档位：见 §2 档位自适应（8192 需求 → 自动 8192）。

## 5. 版本支持口径（决策）

- **v0 交付保证仍只锚定 bai（Cubism 4.2）**，不把 V5.0 提升为 v0 已验证档。
- Cubism 5.0 实证皮套记为「**可解析 + 预览已实测**」：`report` 报 `UnanchoredVersion(V5_0_0)`，UI 需能如实显示「预览」。
- 提升条件（未满足前不动）：≥2 张独立 5.0 皮套 + 真机多后端（WebGPU/WebGL、不同 limits）+ 特性矩阵（expression/motion/pose3/物理）+ 回归门禁。

## 6. 验收与证据

- Windows 15 项自动验收（真机）：启动器/`/app/`/status、mods 发现与 spawn（真 `.exe`）、Job 杀树、日志落点、端口占用退出码 3 + 可读提示、中文空格非 C 盘路径。
- 浏览器：`GPU: webgpu/WebGPU`、物理 4096×3699、FPS 217–240；bai / epsilon_free / 大肥鱼 均完整出画；换模链 epoch/URL 跟随。
- Rust 回归（env-gated，不提交模型资源）：`L2D_EPSILON_MOC3`、`L2D_DAFEIYU_DIR`、`L2D_POSE3_SAMPLE`。
- 发布：v0.5.1 / v0.5.2 的 Windows 包 + CI msvc 产物见 GitHub Releases。

## 7. 未验（如实）

- 5.0 其它皮套/其它 GPU 后端/低 limits 设备矩阵未跑。
- pose3 非空 `Link` 只有合成单测（本机样本 Link 为空）。
- exp3 / motion3 未播放（模型自带资产可用但工程不解析）。
- 关闭 WSL 后双击、双击失败弹窗、桌宠真实窗口：未单独人工验收（与 0.4 线同一批遗留）。
