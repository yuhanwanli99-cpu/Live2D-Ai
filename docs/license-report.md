### 2. Shaders (assets/shaders/) — ❌ Live2D Open Software License

**Files:**
- `FragShaderSrc.frag`, `FragShaderSrcMask.frag`, `FragShaderSrcMaskInverted.frag`, `FragShaderSrcSetupMask.frag`
- `VertShaderSrc.vert`, `VertShaderSrcMasked.vert`, `VertShaderSrcSetupMask.vert`

**Finding:** All shaders have a single comment:
```
// CubismJavaFramework ...
```

They are **adapted from** [Live2D/CubismJavaFramework](https://github.com/Live2D/CubismJavaFramework) (develop branch).
The CubismJavaFramework is licensed under the **Live2D Open Software License**,
as stated in its [LICENSE.md](https://github.com/Live2D/CubismJavaFramework/blob/develop/LICENSE.md).

**Key Restrictions (Live2D Open Software License):**
- **Section 5.6 (No Combination with Incompatible License):** The Source Code may
  not be altered or Distributed in such way as an "excluded license" applies.
  "Excluded license" = any license allowing source redistribution or third-party
  modification (which includes MIT).
- **Section 5.7:** "The Customer may not release any software code or content of
  the Software included in the Software or Output File under a license that is not
  from Live2D."

**Impact:** The shader files **cannot be released under MIT**. They must remain
under the Live2D Open Software License.

**Correction needed:** The file `docs/renderer-algorithm.md` states "Apache 2.0 着色器"
which is incorrect. The shaders are from CubismJavaFramework under Live2D Open
Software License, not Apache 2.0.
