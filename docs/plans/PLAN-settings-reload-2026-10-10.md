# 设置先草稿，保存并重载后才生效

> 立档：2026-10-10。状态：**活**。真源：本文件。配套提示词 `docs/plans/PROMPT-settings-reload-2026-10-10.md`。
> 不升版本，不打 tag，不提交，不推送。不动 `melo/start.sh`、`.env`、`mods.json`、`live2d-ai.toml`。

## 现状

服务端设置（语言模型、语音、人设、动作幅度等）已经是草稿。底部按钮文案是「保存」。成功后服务端热重载或只重启 18080 进程，然后 `reloadAppPage()` 刷新 `/app/`。关设置、关浮层、换分区时，若 `SettingsController.dirty`，弹出已有的「有未保存的改动」（留下 / 保存并离开 / 放弃改动）。

本机偏好不是这条路。主题、背景、缩放、口型、待机、渲染档位、拖动、音量、静音经 `_updatePrefs` **立刻**写入本机存储并下发舞台。所以改档位不会出现未保存条，退出也不弹那三个按钮。

渲染档位 4K / 8K / 16K 的绘制倍率是 1.0 / 1.5 / 2.0，乘在舞台 CSS 尺寸上。普通舞台只有大约 780×230，三档到不了 8192。

## 档位：4K / 8K / 16K 是画布最长边

这就是渲染档位。三档最长边为 **4096 / 8192 / 16384**，另一边按舞台宽高比跟着走，不把画布撑成正方形。8K（8192）落在 wgpu 缺省上限里。16K（16384）先问适配器的 `max_texture_dimension_2d`：报得出再申请；申请或 `configure` 失败就降到 8192，再失败降到 4096，再不行退回「CSS 尺寸 × 设备像素比（最高 1.5）」。舞台照常打开。HUD 印**实际**分到的边长。

现在的 1.0 / 1.5 / 2.0 倍率去掉。缺省 4096。三个选项放在这一页，不包在开发者模式里。

模型贴图仍是清单里的那张。出厂白模型是 4096×4096，8K/16K 画布是超采样，不会凭空多出贴图细节。`texture_00.png` 不写进 `model3.json`。

## 页面改名

设置导航和页标题由「Live2D 动作」改为 **Live2D 设置**。枚举仍是 `SettingsSection.motion`。副标题「舞台与口型、拖动缩放」不动。同步 `settings_sections_test.dart` 里钉住旧标题的那条断言。历史计划书里的旧名字不改。

## 要改的

1. 本机偏好的改动先进草稿：界面滑条和开关显示新值，**不**写本机存储，**不**下发舞台，**不**改正在播放的音量。已保存的那份继续驱动当前舞台。
2. 设置底部按钮在「服务端草稿或本机偏好草稿」任一有改动时出现，文案改为 **保存并重载**。点下去：有服务端草稿就走现有保存（写盘 + 热重载，需要时只重启 18080）；有本机偏好草稿就把草稿写入本机存储。两样都成功之后**只刷新一次** `/app/`。只改了本机偏好时不重启 18080。失败留在设置里，不刷新，草稿还在。
3. 退出前提示沿用现有弹窗，三处拦截不变（换分区 / 关设置 / 关浮层）。任一草稿有改动就弹。保存并离开走第 2 步；放弃丢掉两份草稿，舞台回到已保存的偏好；留下就留在设置里。
4. 选进背景库的新图片字节仍可先写入 IndexedDB，否则草稿没有图可指。放弃时删掉这次新加、尚未写进已保存偏好的那些 id。舞台在保存并重载之前仍显示已保存的那张。

## 不做

- 不把画布撑成正方形，不换模型贴图，不把 `texture_00.png` 写进清单。16K 分配失败必须降级，不得因此打不开舞台。
- 不改口型、分句、TTS、`start.sh`、导演 cue、待机开关的产品语义（待机那份已收的代码别动）。
- 不升版本，不打 tag，不提交，不推送。

## 验收

1. 导航第五项是「Live2D 设置」。把档位从 4K 拨到 16K：舞台 HUD 的物理尺寸不变，底部出现「保存并重载」。关掉设置，弹出「有未保存的改动」。放弃后档位回到 4K，舞台不变。
2. 再拨到 8K，点保存并重载。页面重新加载后，物理尺寸的最长边是 8192，宽高比与拨之前的 CSS 盒一致。再保存到 16K：设备报得出 16384 时最长边是 16384，报不出时停在 8192，HUD 与实际边长一致，舞台仍在。18080 进程在只改档位时不被换掉。
3. 改一条服务端设置（例如记住几轮）再改档位，一次保存并重载：toml 已写入，页面只刷新一次，两处都是新值。
4. `cd shell/flutter && flutter analyze && flutter test`。动了 wasm 就在 `crates/l2d-wasm-demo` 里执行 `env -u NO_COLOR trunk build`。Flutter 用 `/home/skystar/flutter/bin/flutter`。
