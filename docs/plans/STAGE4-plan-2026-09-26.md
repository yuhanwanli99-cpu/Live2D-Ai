### 4c — 渲染面字段化通道 + 音频时钟 + 事件级 ack

**必做**

1. 字段化：`body` / `head` / `expression` → 每皮套映射表；同类 **add**；`hold` 不回基准。
2. `expression` **只写五官**（V3）；头身分量不再由表情下发。
3. **stage-clock 消息**（`{seg,pos_ms,playing}`）替代 `performance.now()` 当 `now_ms`（V7）。
4. **事件级 ack 四条** + 段结束（V8）；缺参数发 `preset_dropped`（不得静默）。
5. 白名单**保持现状**（13 个标准参数，不改 `ALLOWED_PARAMS` 的集合）；
   每皮套基础强度 = 现有 `[action]` 三倍率（§5.3）。
6. 回归（§4.3）+ 负对照（§4.6）。

**明确不做**：不开非标准参数（翅膀 / 耳朵 / 光环…，O11）；不改 `preset_id` 旧路径语义；
不删 `PresetRuntime` 双槽；不改口型 `ParamMouthOpenY`。

### 4d — 前端接线（ack 消费 + 取消纪律 + 时钟下发）

**必做**

1. 消费渲染面 ack → 汇入日志文本（喂导演，V8/§7.3）。
2. 下发 stage-clock（30ms / 帧），段边界用现有 `sentenceStarts` + 新「段结束」事件（V7）。
3. 停止 / 新消息：清动作 + 表情 + TTS 待播 + 回 baseline；**同步取消、不补帧**（V7/V10）。
4. **删掉前端猜 preset 剩余时长的本地定时器**（v0 的 `presetStatus` 类实现）——真源在渲染面（V8）。
5. 回归（§4.4）+ 源码扫描判据（D14 口径）+ 负对照（§4.6）。

**明确不做**：不在前端复制状态机 / 不建前端镜像；不改 WS `action_cue` 帧结构。

### 4e — 会话 baseline + host 接线 + 收口

**必做**

1. `session_scope.rs`：baseline 作为 `prompt_for(...)` 的**兄弟字段**（同表、同会话键、
   同 `sanitize_session_id` 闸），**不新造第二套会话表**（V10）。
2. host：停止 / 新消息 → 清三样 + 回 baseline（V10）；与 4d 的取消纪律对齐。
3. director 二路产出面能表达三字段（V12 事实下只产 cues）。
4. 回归（§4.5）+ 全量门禁 + 端到端 + 收口报告。

`desktop/src/main.rs`（**需要动 → 停下问维护者**）。

## 5. git 门控（维护者执行；worker 与编排者**一律禁止** git 写操作）

  出现越权路径 → 该轨退回。
