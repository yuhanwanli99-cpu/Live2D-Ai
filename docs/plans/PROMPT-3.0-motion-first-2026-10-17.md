## 2026-10-18 版本号 `0.x.y-rc.z`（维护者裁决）

与下文 2026-10-17 的句子冲突时，以本节为准。

写法是 `0.x.y-rc.z`（带点，例如 `0.3.2-rc.1`）。

- `0.x.y` 通常指定一块具体功能。下一块功能用下一个 `0.x.y`。
- `z` 有意不事先钉死。执行这一块的 agent 按代码把实现拆成小任务，每步一个 `0.x.y-rc.z`。`rc.1` 到 `rc.z` 都在做这块功能。每步换一队 agent。
- 最后一个才是 `0.x.y-rc.(z+1)`：只做这块的拆分、测试、文档、棘轮。不加功能。清理不另开一个 `0.x.y`。
- 每个 rc：一次本地提交 + 一个本地附注 tag。不 push。远端由维护者验收后自己提交。
- `Cargo.toml` / `pubspec.yaml` 的版本串仍停在发布口径，不随本地 rc 改。

已落定的 0.3 线保持不变：`0.3.1` 外部事件忙时合并，`0.3.2` 手势到期放回与导演并入核心，`0.3.3` 分仓库，`0.3.4` 多 TTS/LLM + `local-engine`，`0.3.5` 多 Live2D。没有单独的 `0.3.6`。

其后：`0.4.0` 只做 Windows 支持（同一套 `--web` 二进制；已落地、本地 rc.1…rc.3 未 push）。`0.4.1` 已落地。`0.4.2` 已落地。`0.4.3` 桌宠 demo 已派（只透出皮套，不建新 Mod crate，禁止 `pet-desktop`）。

## 全程都在的锁

- 动作只走 `action_cue` → 渲染面 `preset`。`ModServices.action_tx` 继续休眠。`action_request_is_dormant_not_delivered` 保持。
- 不整篇情绪分类，不把标签写进台词，不随机表情，不跨轮常驻，不照 N.E.K.O 重做情绪模型。
- 出厂 `system_prompt` 为空。角色卡仍只在用户自己启用 `persona` 之后导入。
- 对话模型与出厂 TTS 不改。出厂 TTS 仍是 Melo `http://127.0.0.1:8091/v1`。
- TTS / LLM 的协议留在核心 `[tts]` / `[llm]`。
- 不挂回 `pet-desktop`、`wallpaper`、`local-llm`、已封存的 CosyVoice `local-tts`。
- 源码 `>500` 棘轮在无版本号拆分（`15cdfa0`）收紧为 **22**，desktop deps 棘轮收紧为 **18**。不得放宽。`>1000` 仍是 0。`preset/mod.rs` 保持 ≤1000。`RATCHET_DART_800` 仍是 0。docs 预算仍是 45000。
- wasm 体积超过 4.2 MiB 是已知停点。不改预设、不降 `WASM_DIST_BUDGET_MIB` 去追体积。
- 这些保持原样，不要夹进任何一版：快捷键帮助里的「停止本轮」、仓内 `docs/examples/bilibili-sidecar/`、主动点头、示例里的 `[tts].channels`、`docs/design/web-ui-spec-v3.md` 的枚举表、`docs/audit/2026-10-09-silent-errors/FINDINGS.md` 正文、调试面板的位置。

- 测试前清掉 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY` 以及小写同名变量。`flutter` 在 `$HOME/flutter/bin`。
