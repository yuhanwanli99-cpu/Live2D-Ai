# v0.2.0-rc.1 — Mod 纪元第一基线：external-input 直播刚需 + 社区许可（2026-09-14）

> 版本线由 `0.1.0-rc.5` 进入 **`0.2.0-rc.1`**：不是 rc.5 的增量补丁，
> 而是**外部事件（直播弹幕/礼物）成为一等刚需**后的第一个基线。
> 上游基线：[v0.1.0-rc.5](v0.1.0-rc.5.md)（tag `v0.1.0-rc.5` = `0883c1d3`）。
> 范围真源：本轮任务书逐条列出的「必做 / 禁止」+ `docs/plans/PLAN-0.2.0-rc1-mod-era-baseline-2026-09-14.md`。

## 1. 一句话

把「外部事件注入」从半成品做成**可对接的刚需链路**：一条 loopback 契约
（`POST /api/v1/external/chat`，文档 + curl + 错误表）、一个加强的
`external-input` Mod（静态 `settings_spec` / 模板前缀 / 启停门禁）、
一个 **Windows sidecar 示例**（blivedm 抓 B 站弹幕/礼物 → 清洗 → POST）；
同时**废除 `local-llm` 启动**、把 Mod 社区许可与分发门槛写成明文。

## 3. 语义钉死（避免下一轮再解释一遍）

1. **B 站抓取不在主仓，在 Win sidecar。** 主仓只做 loopback 端点 + `say`；
   协议 / blivedm / WSS / 开放平台 SDK / cookie 鉴权一律不进 Rust。sidecar 挂了只影响
   弹幕注入，**不影响主链路**。
2. **启停唯一真源 = Mod manifest 的 `enabled`。** settings 里**不再**有第二个
   `enabled`；停用后端点返回 `403 mod_disabled`，**不静默吞文本**。
   `0.2.0-rc.1` 起 `external-input` **缺省启用**。
3. **token 优先级：env `EXTERNAL_INPUT_TOKEN` > Mod config `token` > 不鉴权。**
   请求侧 body `token` 或 `Authorization: Bearer` 二选一。
4. **模板在前缀之后**：先 `text_template`（`{text}` 占位符）再拼 `prefix`；
   长度对**渲染后**文本判定。
5. **local-llm 废除启动**：不再注册、不再编译进 binary；LLM 端点由 `live2d-ai.toml`
   的 `[llm]` 显式配置。crate 暂留仓库 ≠ 可用；**禁止挂回**。
6. **persona 不回退**：主链 `[persona]` 仍只有 `system_prompt` +
   `max_history_pairs`；角色卡仍由 `persona` Mod 承担。
7. **主链皮肤冻结**：LLM/TTS/口型/Live2D、壳/舞台背景、等待机生命体征——一行未改。

## 4. 升级注意（从 rc.5 过来）

- **`mods.json`**：如果你之前的 `mods.json` 只写了
  `{"mods":{"local-llm":{"enabled":true}}}`，升级后 `local-llm` 只是被忽略
  （不再注册），但 `external-input` 会因文件**完全覆盖**内建缺省而**保持停用**：
  建议把 `external-input` 的 `enabled` 设为 `true`（仓库根的
  `mods.json` 已示范），或在「Mod 管理」里打开。
- **本地 LLM 用户**：不再有自动探活 / 写入 `base_url`；请在
  `live2d-ai.toml` 的 `[llm]` 手填 `base_url`（`127.0.0.1:11434/v1` 等）。
- **弹幕接入**：从 `docs/examples/bilibili-sidecar/` 起，先 `SIDECAR_DRY_RUN=1`
  确认，再接真的 `BILI_ROOM_ID` / `BILI_SESSDATA`。
- **旧文档**：`docs/architecture/external-text-input.md` 是 Python 时代的历史，已加
  横幅标注；当前契约只看 `docs/external-input.md`。
