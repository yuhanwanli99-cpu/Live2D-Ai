# Live2D-Ai v0.1.0-rc.1 — 核心链路基线

> **首个对外候选版（RC）**。版本线由 `0.5.1` **重置**为 `0.1.0-rc.1`。
> 平台：Linux / WSL2（PC 主力）；Android、原生 Windows 不属本次范围。
> 公开历史已**重新起算**（单根提交）——见下方「历史重置」一节。
> 基线说明：[`docs/architecture/core-chain-baseline.md`](../architecture/core-chain-baseline.md)；
> 交接：[`docs/plans/HANDOFF-2026-09-11-core-chain-baseline.md`](../plans/HANDOFF-2026-09-11-core-chain-baseline.md)。

## 为什么重置版本线

本版**不是** 0.5.x 线上的一次增量，而是把「核心链路」重新定义之后的第一个候选版：
LLM 工具层与动作系统已从前后端**整体拆除**（LLM 不暴露任何工具，只做对话），
音频播放路径换成媒体元素，句界契约改由引擎给出。

按 `0.5.2` 递增会让一次「拆除」看起来像小修补，所以重新起算到 `0.1.0` 线的 RC。
版本号唯一真源是 `Cargo.toml` 的 workspace `version`（各 crate 继承，
代码经 `env!("CARGO_PKG_VERSION")` 编译期固化，暴露于 `GET /api/v1/app/capabilities`）。

## 核心链路（本版的定义）

```
文本 → LLM（纯对话，无工具）→ TTS（一句一单元）→ 口型 → Live2D 皮套渲染 + 前端 UI
                                                       + 相关设置等基础设施
```

逐环出处与证据见 [`core-chain-baseline.md`](../architecture/core-chain-baseline.md)；
一键端到端验收：`python3 scripts/verify_core_chain.py`（17 跳）。

## 主要变更

### 1. 拆除（破坏性）

- **LLM 工具层**：请求体不再出现 `tools` / `tool_choice` / `functions`
  ——有回归测试 `llm::tests::wire_request_has_no_tools_key` 断言这三个键**不存在**。
- **动作系统**：前端动作快捷按钮 / 动作历史 / 动作来源徽章，后端 `/api/v1/commands`
  与 command registry、tool adapter、`runtime/tool.rs`、`dialogue/tool.rs` 全数删除。
- **保留但休眠**（刻意，非遗漏）：`live2d-ai-core` 的 `action` / `performance` 子系统、
  `live2d-ai-mod-director` Mod、`ModServices.action_tx`。它们仍属 Mod API 契约，
  但**没有任何自动驱动方**——是休眠，不是「待接线的空壳」。
- **保留且必须保留**：**待机生命体征**（`IdleState` 的呼吸 / 眨眼 / 微表情）。
  这与动作系统是两套机制，删了皮套就不动。

### 2. 音频路径：Web Audio → 媒体元素

起因是用户报「浏览器里禁用了声音，但依旧有声音传出」。

- 播放从 `AudioContext` 逐片调度改为 **`<audio>` 媒体元素 + Blob(WAV)**。
- 静音 / 音量直接落在 `element.muted` / `element.volume`，**不再**折成 `GainNode` 增益——
  Web Audio 归 Chromium 的 autoplay 策略管，而「站点声音 = 阻止」作用在**媒体元素**上。
- 后端经 WS 下发 PCM（按句分片，带 `start` / `end` / `sentence_seq`），
  前端按句封 WAV 交给媒体元素，口型用 `audio.currentTime` 查服务端 `volume` 包络。
- 本机 TTS 实测**出不了 mp3**（`mp3` / `wav` 请求均 HTTP 400，只有 `pcm` 200），
  所以「推文件」只能是 WAV。

### 3. 三个真缺陷（真机点火抓到，均已修 + 有回归）

| # | 缺陷 | 根因 | 修法 |
| --- | --- | --- | --- |
| ① | 句子边界错乱 | 发射侧用 epoch **记账推断** `start`，实测一句产出 **0 个 start / 13 个 end**，前端把一句切成十几段播 | 句首/句尾改由引擎 `EngineEvent::AudioChunk` 的 `first_chunk` / `final_chunk` 给出 |
| ② | 整轮对话失败 | 分句器把换行也算句读 → 产生**纯空白句** → 上游回 `400 {"detail":"input 为空"}`，而 TTS 错误是 **fatal** → 整轮判 Failed | 空句**不发** TTS 请求，走静音句路径 |
| ③ | 句子没有句尾闸门 | 句子样本数恰为 `audio_chunk_samples` 整数倍时末块 0 样本，被当空包丢弃 | **空末块也发边界帧**（`audio: ""` + `end: true`） |

### 4. 前端门禁与离线红线

- **字体子集门禁**：界面文案不得出现自托管子集外的字符。
  真机上实测到 `GET https://fonts.gstatic.com/s/notosanssc/v37/…woff2 [200]`
  ——流式光标用了 `▍`(U+258D)、macOS 前缀用了 `⌘`(U+2318)，都不在子集里，**断网即豆腐块**。
  修法是改成不依赖字形的实现（光标画竖条、`⌘` 改 ASCII `Cmd`）+ 门禁
  `test/font_subset_test.dart`。
- **构建必须带 `--no-web-resources-cdn`**（否则 CanvasKit 指向 Google CDN，断网白屏）。
- **压在舞台 iframe 之上的可交互控件必须套 `StagePointerInterceptor`**
  （漏套不报错，只是「看得见、点不着、也滑不动」）。

## 历史重置（重要）

本仓库的**公开历史**于 2026-09-11 **重新起算**：`main` 现在是**单个根提交**。
旧开发历史（Python 时代的 `Live2D-Ai-pc/`、Android 工程，以及其中一处
**60 MB 的调试 APK** 和 **Live2D 模型二进制**：`bai.moc3` 8.6 MB + 贴图 10.9 MB
+ 约 36 MB 的 ORT wasm）**不再包含在公开仓库中**。

理由两条：

1. 公开历史里躺着 **Live2D 模型二进制与贴图**，与本项目「模型不捆绑分发、
   由用户合法取得」的立场**自相矛盾**；
2. 公开仓库 `.git` 达 **256 MB**，而产品树只有 **19.7 MB**——历史是产品的 13 倍。

处置与保全：

- 旧代码**只存在本地**：维护者侧保留了全历史 bundle 与
  `archive/full-history-*` 分支、`android-archive` 本地分支、`py-legacy` 标签，**未丢失**。
- 基线标签 `baseline-core-chain-2026-09-11`（指向 `28de52cf`）**已从远端移除**，
  仅在本地保留——否则它会把整条旧历史继续挂在公开仓库上。
- **已克隆过旧仓库的副本需要重新克隆**（单根提交与旧历史无共同祖先，普通 pull 会冲突）。
- 旧提交对象在 GitHub 上仍可能按 SHA 访问一段时间，直到 GitHub 侧执行 GC。

## 已知限制（本版**未**做）

- `live2d-ai-core` 的动作 / 表演子系统**休眠**：保留代码，无驱动方。
- `GET /api/v1/app/capabilities` **仍**声明 `actions` / `action_sources` / `strength_levels`,
  与实际能力不符（已知文档债）。
- `crates/l2d` 的模型支持是 `is_supported_v0()`——**只认 moc3 原始字节 4（Cubism 4.2）**，
  所以「通用接入容器 / 不限定模型」目前在工程上**尚未成立**。
- `persona.system_prompt` 出厂为**空**字符串；建议填入人设提示词以减少空回复与跑偏。
- `live2d-ai-mod-pet-desktop` 为 v1 骨架，窗口生命周期尚未接线。
- Mod 侧 `action_tx` 通道**休眠**（见上）。

## 安装与运行

```bash
cp live2d-ai.toml.example live2d-ai.toml    # 配置 LLM / TTS（OpenAI 兼容）
cargo build --release
./target/release/live2d-ai-desktop --web --http-port 18080
# 浏览器访问 http://localhost:18080/
```

平台二进制（Linux / Windows / macOS）由 `.github/workflows/release-build.yml`
在 `v*` 标签上构建并作为 Actions artifact 上传（**不**发布到 GitHub Releases）。
