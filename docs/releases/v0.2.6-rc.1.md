## 这一版

收的是 `v0.2.5-rc.1` 之后已经验收、此前没有入库的一轮：

1. **手势**走攻击、保持、放回。待机摆头在手势占着槽时让开。呼吸和眨眼不动。
2. **同槽换另一个动作**从屏幕上这一帧的姿势接过去。同一 id 再来仍从 0 重开。空槽第一次出手势仍从 0 起。
3. **表情**用同一条曲线。进度 0 和 1 是 0，保持段是满的。`preset_id == "none"` 从屏幕上的值收回去，到点再清槽。时间到仍立即清槽，因为那一帧已经是 0。
4. **播放中只有一颗停止键**：停本轮，丢掉还没播完的声音和动作。
5. **本句 TTS 或解码失败**：这一句静音，后面的句子继续。下划线只在 Melo 合成前去掉。屏幕上的字不动。
