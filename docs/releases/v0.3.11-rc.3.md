## 1. rc.1 点火：撤掉 600 秒本机 TTS 等待与 Melo 清理（提交 `a728d4a`）

- `scripts/ignite.sh`：删掉 `[tts].mode=local` 对 `GET {tts}/models` 的 600 秒循环、
  15 秒一行「仍在等待」与超时 `exit 1`。维护者 2026-10-20 的点火日志里，服务早已
  `GET /app/ = 200`，却因为 8091 没有 Melo 空等 10 分钟后退出码 1。
- 删掉启动前对同级 `melo/serve.py` 与 `engine/` 的 `pkill`：缺省二进制不拥有这些进程，
  用户可能自己拉起 Melo，点火脚本没有资格杀它。替换本服务的
  `pkill live2d-ai-desktop --web` 保留。
- 就绪判据改为 `GET /` = 200（启动器页）；仍是 302 的旧构建回落等 `GET /app/` = 200
  （中间 rc 兼容，不删）。就绪后打印 `http://127.0.0.1:<port>/` 并开浏览器，不再等本机 TTS。
- `--check`：`GET /` = 200 且正文含 `live2d-ai-launcher`；`GET /app/` 仍 200；
  CDN 探针不变，并新增「启动器正文不得引用 `gstatic.com/flutter-canvaskit`」
  （与产物共用 `scripts/lib/cdn_probe.sh` 的判定）。
- `curl -w "%{http_code}"` 后跟 `|| echo 000` 会拼成 `000000` 的写法，统一走 `http_code`
  helper（只留三位，拿不到就是 `000`）。
- `tests/test_shell_scripts_syntax.py`：local 不再要求「等待本机 TTS 就绪（缺省不自动拉起）」；
  cloud 仍必须出现「云端端点，不等本机进程」；判据仍只认 `[tts].mode`，不按主机名猜。
