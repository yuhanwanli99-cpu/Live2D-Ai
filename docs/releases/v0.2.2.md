## 这一版

1. **上屏句号**。有正文的 `text_delta` 带 `sentence_seq`（从 1 起，与音频帧同源，文本与送去 TTS 的那一句逐字相同）。完成锚点（带 `completed`）和 `reasoning_delta` 不带这个字段。缺字段的旧帧前端读成 `null`。
2. **会话历史分桶**。引擎仍只装一份历史。每一轮开始前，宿主按 `session_id` 换桶；没有会话 id 的走全局桶。成功轮仍由 `commit_completed_turn` 提交。失败和停止仍不提交。热重载成功后分桶与新引擎一起清空。只在进程内存，不写盘，也不改 memory 的 JSONL。

朗读高亮（T3）和文档索引三处指针（T4）留给 DeepSeek，管理员审查后再收。
