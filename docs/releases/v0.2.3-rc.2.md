# v0.2.3-rc.2 —— 语音二选一、设置一步生效、渲染档位、调试归位

> 发布日：**2026-10-10** · 上一版 tag：`v0.2.3-rc.1`（`5af352c`，已在 origin，**不移动**）
> 本 tag 盖住 `v0.2.3-rc.1` 之后已在 `origin/main` 的两笔：`c14240a`（现行句与启动命令）、`e2c3344`（下面四件事）。版本号写在紧随其后的这一笔里。

## 这一版

1. **语音来源二选一。** 缺省本地：`127.0.0.1:8091`、音色 `ZH`、`pcm`、44100、单声道、无密钥，并只启用 `local-tts-melo`。云端必须在同一次保存里给出非空地址和音色，否则整次 `400`，不静默改回本地。连通性自检仍只打 `/models`。
2. **保存一步。** 写盘后能热重载就热重载。需要重启时只替换 18080 上的本进程，且只有真服务进程 `arm()` 之后才会自重启。失败不改已写入的配置，旧进程继续服务。
3. **启用 Mod 不堵住接受循环。** 存在性判定之后立刻回 `202 {"ok":true,"pending":true}`，动作在后台线程。`GET /api/v1/mods` 带 `last_error`。
4. **渲染档位改绘制分辨率。** `RenderTier::render_scale()` 为 1.0 / 1.5 / 2.0，乘进画布位图。`side()` 仍是最后一道保比上钳。表情调试、动作调试、临时幅度改挂在导演卡片；核心开发模式页只留开关和诊断。

`c14240a` 只改文档：现行句对齐 `0.2.3-rc.1`，并写上标准构建与 `./scripts/ignite.sh` 启动。

## 不在本 tag 里

- `melo/start.sh` 用 Python 3.10 安装 MeloTTS 的修改还在工作区，没有进这次提交。本 tag 里的脚本在只有 Python 3.14 的机器上仍然装不上。
- 待机开关仍只停眨眼和微表情。`PoseStack` 每帧的 `ParamAngleZ` 摆动不看这个开关。物理输入不含 `final_override`，头发跟着 ±3°，不跟着导演写上的角度。这两条不在本 tag。
