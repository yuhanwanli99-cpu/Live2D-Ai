`WebDevice::create_buffer` → ayagami `load_model`。本块先用 panic hook +
`[swap]` 分阶段日志取证，在 **Windows Chrome 152 真 GPU（NVIDIA）** 与
**Chrome 153 SwiftShader** 上跑了 10 组场景（顺序双向 / 同 tick 并发 / 30ms 连发 10 条 /
同 URL 两次 / preset+stage-clock 播放中换 / 坏 physics3 故障注入走旧回滚路径 /
`sync.payload.model` / `?model=` / /app 真 UI）：**零 panic、零 targetCrashed**，
原始第一行 panic 文本**未取到**，根因**未定位**。

修法 B（已落地）：`ModelRendererCore::load_fresh` 在同一个 `GpuContext` 上新核心从零装载，
成功才 `*core = fresh` 原子替换；失败旧核心一个字段都没被碰过，**删除「再 load 旧 URL 回滚」**
（那是对同一 renderer 的第二次 `load_model`，也是 0.3.5 panic 栈顶对应的唯一路径）。
`swap_core` 抽成平台无关状态机（native fake loader 单测：成功 / 坏 URL / 装载失败旧核心不变 /
连点只装最后一次）。panic hook 保留，真机再炸能拿到第一行文本。

**未验边界**：panic 原文与根因未定位；只有 headless（非 headless Windows、0.3.5 当时的

## 2. cue / field map 重绑（model_epoch）

- 渲染面 `model_epoch`：首装 1，**只有成功换模 +1**；失败不换 epoch、旧模型与旧 cue 不动。
- `loaded` 带 `model_id` / `model_epoch` / `field_map{source,degraded,reason}`；
  换模失败 `error` 带当前旧模型身份。全部渲染事件 ack 与 `stage-ack` 盖 `model_epoch`。
- 上行 `preset` 帧带旧 `model_epoch` → 渲染面 **Ignore**（不写参数、不发 ack）；缺字段 = legacy 接受。
- Flutter 只认当前 epoch：换模成功（匹配 URL 的 loaded）后清 `DirectorCuePlan` /
  `PresetStatus`、下发一次 `preset none`、按新 `model_id` 重设 `ActionScalesSyncer`
  并补发有效幅度；失败全不动。dev_mode 导演可观测 B/C 栏显示 `model_id` / `model_epoch`。
- `run_swap` 重排为「所有 await 在状态变更之前」，被取代的请求不 install / 不换 epoch /
  不发 loaded（补 fake host 竞态单测）。

## 3. 设置纪律：草稿不生效，只有「保存并重载」

- 设置**表单字段**（含 `[action.models.<id>]` 本模型覆盖）只进草稿；切分区 / 关设置 / 取消
  零写盘零下发；只有「保存并重载」全部成功后才生效，且只刷新一次；失败不刷新、草稿保留。
- 动作幅度（全局三键 + 每模型覆盖）舞台**只吃已保存值**，保存成功后才下发一帧；
  拖动 / 放弃 / 失败都不下发。**行为变化**：撤销了 0.3.5 的「滑条即时预览」与模型覆盖的
  即时 PATCH（不再有保存成功/失败结果位）。
- 新增 `SaveFlow` 唯一编排 + 20 条可失败计数断言（红-绿双向）。
- 显式动作按钮（模型 activate / `.env` 密钥保存 / Mod 启停 / Mod 卡片「保存并应用」）
  保留立即语义；写明例外仍只有模型 activate 与 `dev_mode` 调试临时覆盖。
