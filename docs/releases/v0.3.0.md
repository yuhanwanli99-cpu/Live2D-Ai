# Live2D-Ai Rust v0.3.0

> 对外发布标注：**通用人形皮套 AI 接入一体化平台 · Rust 主线首个稳定版**。
> 平台：Linux / WSL2（PC 主力）；Android、原生 Windows 非本次范围。
> 分支来源：`dev/integrity` → main；Python/Android 双端已归档（`py-legacy` / `android-archive`）。

## 定位

Live2D-Ai 是 **通用人形皮套 AI 接入一体化平台**——AI + Live2D 人形皮套的通用接入与应用层。
**不绑定任何单一模型**（模型由用户合法导入，`assets/models/` 不捆绑二进制），
**不做复杂上层**（核心保持最小最简：核心链路 + Mod 边界）。本版即以 Rust 主线为核心链路
验证「文本/语音 → LLM → TTS → Live2D 表情/口型/动作」闭环。

## Highlights（相对 v0.2.0-preview.1 / Python 时代）

- **Rust workspace 完全主线**：`crates/`（l2d / core / runtime / desktop / wasm-demo / mod-system +
  external-input / pet-desktop / director / local-llm / local-tts）+ `xtask`；Rust 占比 ≥95%。
- **核心链路收口（节点 F）**：Web UI（65/35）+ 设置抽屉 8 分区 + `/render` wasm 舞台；
  `dispatch_event → per-Mod on_event` 路由（SharedRuntime 槽位 + 失败清槽隔离）。
- **5 Mod 开箱即用（P1）**：external-input（`POST /api/v1/external/chat` + token 鉴权）、
  director（config 驱动白名单动作）、pet-desktop（v1 骨架）、local-llm / local-tts（本地推理）。
- **真实性收口（P3 / P3.1）**：release WASM + HighPerformance + DPR cap + 真接线
  （缩放/动作/口型/模型加载 + Mod 配置管道）；用户实测驱动修复（拖动/缩放/动作/背景）。
- **S1/S2 修复（dev/integrity）**：director 动作白名单对齐（`shake_no`）+ supervisor→Mod 事件桥
  （`TurnStarted/ActionFinished/TextDelta/VoiceStarted/VoiceEnded/ModelActivated` 投影）。
- **稳定性基线**：workspace 763 tests 通过；fmt / clippy `-D warnings` / rust-ratio（95.28%）全绿；
  headless 冒烟（home / render / wasm 200 + 5 Mod）。
