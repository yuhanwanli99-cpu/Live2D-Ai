## 1. 这一版是什么

`v0.2.0` 之后的**两轮工程债**（2026-10-05 债轮 + 2026-10-06 补齐轮）。**没有新功能、没有主链契约变更**，
因此是 **patch 级 rc**（不是 minor）。五件事：

1. **字体回落结构性离线化**（缺口 N1）：运行期 `fontFallbackBaseUrl` 从 gstatic 改成**同源**，断网再也不会白屏/出网；
2. **结构硬指标达标**（缺口 N5 / D2）：Rust `src >1000` **4 → 0**、Dart `lib >800` **7 → 2**（= PLAN 目标）；
3. **探针判据修复 + 首次真实音频链路验收**（缺口 N4）：修掉被截图伪影击穿的判据，并第一次端到端验到 `<audio>` 真在播；
4. **CI 三条红线门禁 + 依赖 25 → 22 + Mod 密钥接缝**（审计 F-0048/0049/0050/F-0062）；
5. **安全**：公开历史里写死的**维护者手机锁屏口令**（审计 F-0616-01）——树里删净、扫描器补这一类、**历史清洗**（§6）。

## 5. 本版改了什么（按主题）

### 5.1 结构（D2 / N5）

- Rust：`mod_registry.rs` 1438 → 196（+5 子模块）· `external_routes.rs` 1202 → 442 · `chat_routes.rs` 1086 → 456 ·
  `mod-persona/lib.rs` 1004 → 201；配方沉淀为「**搬测试出 `src` 必须每份 <500 行**，否则 `>500` 计数凭空上涨」。
- Dart：`dev_tools_section` 2109 → 441 + 4 个 part · `appearance_background` 1552 → 724 + 2 · `tokens` 950 → 670 + 2 ·
  `settings_models` 931 → 439 + 2 · `app_shell` 998 → 367 + 1；硬约束「**类体不能跨 `part`**」由实测钉死。
- 棘轮**同 commit 收紧**：`>1000` 4→0、`>500` 48→44、Dart `>800` 7→2。

### 5.2 离线（N1）

- 自定义 `web/flutter_bootstrap.js` 走**现代** `initializeEngine({fontFallbackBaseUrl:'font-fallback/'})`（相对路径）；
- 镜像 5 个**整族**（半族会稳定触发 404→永久失败）→ 未镜像字族离线 = 豆腐块，**明确接受的取舍**；
- `scripts/font_fallback_mirror.sh --check` **不联网**校验「清单 == 磁盘 == 引擎表全集」；
- **实测**：注入 `𠮷`/`🀄`/`𝄞` ⇒ **跨源请求 0/0**，`notocoloremoji` 200、`notomusic` 200、`notosansjp` 404。

### 5.3 验证（N4 + 音频）

- 截图判据两个根因：带 `clip` 的 `captureScreenshot` **稳定全白**；不带 `captureBeyondViewport` **间歇全白**；
  修成整页 + 该参数 + 全脚本禁 `clip`；「不可判读帧」判 **blocked（环境）** 而非产品 fail；
- 背景注入改 **IndexedDB 真字节**（id 与 Dart `backgroundFingerprint` 同算法）；
- CI 三红线：`scripts/lib/cdn_probe.sh` 单一真源 + 秘密扫描扩面 + 构建期产物门禁。

### 5.4 语义

- 「重试」= **重发上一条用户消息**（全仓 3 条读输入框的静默 no-op 全部清掉；无上一条 ⇒ 按钮不出现）；
- 「运行态（只读）」块改判为**没有专用面板的 Mod 的兜底面**（原判「不可达」被回源码证伪）；
- Mod 配置保存不再抹掉 `secret` 字段（F-0062-01）。

### 5.5 治理

- 审计台账 952 文件入库 `docs/audit/2026-10-05-ledger/`（含仍未关闭的 6 条 P1 清单）；
- 文档残留对账（豁免口径 / 更名的测试文件）。

## 6. 安全与历史清洗（本版最重要的运维动作）

**事实**：`scripts/deploy_android.sh` 自 `v0.1.0-rc.1` 的根提交起就在**公开远端**上，头注与 `PHONE_PASSWORD`
默认值里写死了维护者**手机的锁屏口令**。

**处置**：
1. 删除该脚本（它自 2026-09-11 起就指向已归档、树里不存在的 `Live2D-Ai-Android/`）；
2. `scripts/check_public_secrets.py` 补「文字口令 / 纯数字口令 / 中文『密码:』」三类模式（旧四条只认云厂商 key 形状）；
3. 台账摘录**脱敏**；
4. **历史清洗**（`git filter-repo`，本轮执行）：从**全部 573 个提交**中删除该路径，并把两个标识串
   （5 位数字口令 / `192.168.0.x`）替换为脱敏值。

**验证**：新旧 `main` 的**树哈希完全相同**（`c5f82d3d0e8ed9e2b8289e42c2358f4f902cd47b`）⇒ 清洗只动历史、
没动当前内容；新历史里两个 needle **0 命中**；独立验证见 `docs/audit/2026-10-06-purge/PURGE-VERIFY.md`。

**仍然残留（如实记录）**：
- 远端 `refs/pull/1/head` 由 GitHub 托管，**我们推不动也删不掉**；它可能仍指向清洗前的对象；
- GitHub 侧旧对象在被 GC 前仍可能通过直接 SHA 访问；
- ⇒ **轮换那台手机的锁屏口令才是真正的修复**（维护者动作）。

**维护者验收**：维护者 2026-10-06 确认肉眼/听音验收通过，并指示退役勾选表 ⇒ 本版**删除**
`docs/verification/v0.2.0-checklist.md`（历史上它就不是门禁）。
