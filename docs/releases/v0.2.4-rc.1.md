# v0.2.4-rc.1 —— 本机出声接上、待机开关、设置草稿、渲染档位、TTS 生命周期

> 发布日：**2026-10-10** · 上一版 tag：`v0.2.3-rc.2`（已在 origin，**不移动**）
> 本 tag 收的是 `v0.2.3-rc.2` 之后的一整轮：把「8091 真的应答」做成日用、
> 补上 rc.2 明说不含的两条（`melo/start.sh` 安装、待机开关 + 物理跟导演），
> 再把设置改成「先草稿、保存并重载」，并给 spawn 出的本地 TTS 子进程钉死生命周期。

## 这一版

1. **本机发声真的接通（MeloTTS / 8091）。** `melo/start.sh` 重写为可复现安装：
   `.venv` 里 `import melo` 不成立就删这一个目录、用 **Python 3.10** 重建（系统 `python3`
   是 3.14，而 tag `v0.1.2` 的 `setup.py` 用了 pip≥10 已删除的 `pip.req`，装不上；
   找不到 3.10 直接非 0 退出，**不退回 3.14 重试**）；对 `setup.py` / `api.py` /
   `japanese.py` 各打**一处**幂等补丁（前者改读 `requirements.txt`，中者接受
   `config_path` / `ckpt_path`，后者 MeCab 改用 `unidic_lite` 的词典）；
   `bert-base-multilingual-uncased` 仍不入库，落在 `melo/.cache` 当 `HF_HOME`，
   启动前缺则下载、下不到就点名报错。`melo/.src/`、`melo/.cache/` 进 `.gitignore`。
   实测：一轮对话的两句原文分别打到 `POST /v1/audio/speech` 得 **200**，浏览器 `<audio>` 出声。
2. **待机开关 + 物理跟导演。** `PoseStack` 增加 `idle_enabled`：关掉待机时**连每帧的
   `ParamAngleZ` 摆动也停**（rc.2 只停眨眼/微表情），并把导演写上的角度并入物理输入
   （头发跟着动，不再固定 ±3°）；`ModelRendererCore::load_model` 换栈时**抄走**
   `idle_enabled`（修掉「切模型后开关被重置」的静默失效）。
3. **设置先草稿，保存并重载才生效。** 界面上的本机偏好（缩放 / 口型 / 待机 / 渲染档位 /
   主题 / 背景 / 音量 / 静音）改动只进**草稿**，不落盘、不下发、不改音量；底部「保存并重载」
   一次提交（服务端草稿 + 本机偏好），需要时**只替换 18080 上的本进程**、只刷新页面一次；
   有关闭/切换/刷新前有未保存改动会**确认**，可「放弃」。音量/静音从**草稿**起稿
   （不冲掉已改过的其它字段）。
4. **渲染档位改绘制分辨率（最长边）+ 运行时逐级降级。** 档位不再乘 `render_scale`，
   而是画布**最长边**（4096 / 8192 / 16384，另一边按 CSS 宽高比，**不撑成正方形**）。
   运行期先抬 adapter 的 `max_texture_dimension_2d`，再按「档位 → 8192 → 4096 → CSS×DPR」
   **逐个** `get_default_config` 申请，申请不到就降一档；全失败则保留原数据、**舞台照常打开**
   （初始化与 `sync_canvas_size` 共用同一个回落循环）。
5. **本地 TTS 子进程的生命周期 = 主程序。** spawn 时给子进程装
   `PR_SET_PDEATHSIG = SIGKILL`：桌面端被 **SIGKILL/强杀**（不走 `shutdown()`）时，
   内核兜底把 melo / CosyVoice 一起收掉，不再留下占着 8091 的孤儿。`scripts/ignite.sh`
   另加一条预检：升级前遗留的孤儿（只认本仓 `melo/serve.py` 与 `engine/`）在点火前
   点名清掉。**实测**：`kill -9` 桌面端后，melo 子进程随之消失、8091 立刻释放。

## 边界（如实登记）

- `PR_SET_PDEATHSIG` 是**全仓唯一一处 `unsafe`**（工作区 `unsafe_code = "deny"` 下的
  局部 `#[allow(unsafe_code)]`，附 SAFETY 说明）：`prctl` 没有安全封装，且这是「父死即
  收子」唯一的内核级保证。只编译进 Linux（进程宿主 = WSL2；Windows 侧只跑浏览器）。
- 渲染档位 16384 在软件渲染（swiftshader）下极慢，只作能力上限，不是日常档；档位默认 4096。
- 计划书里「不重开设置信息架构」「不挂回 CosyVoice3 / `local-tts`」「不接回 `action_tx`」等禁令
  继续有效；本版没有触碰 `live2d-ai.toml` 的人工段、`.env`、`mods.json`。
