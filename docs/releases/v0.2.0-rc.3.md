## 4. 语义钉死 / 行为变更

1. **语音选「专用端点」而不是复用 `/api/v1/external/chat`**（任务书要求二选一写清）。
   理由写进 `docs/voice-input.md` §8/§10：voice 有自己的 `token`/`locale`/`backend` 语义，
   且**要让 `live2d_ai_mod_voice_input::clean_transcript` 真的跑在主链路上**（复用 external
   只会让 voice-input Mod 继续当摆设）。两者落点相同（都是 `supervisor.say`）。
   `backend`/`locale` 目前**只是配置 + 启动日志**，不参与清洗或请求体——**推模式**：
   Rust 侧不开 socket、不连 sidecar（别在发布口径里写成「Rust 会去连 sidecar」）。
2. **壁纸不再说假话**：`apply_decision`（对非 `None` 决策 warn + 返回 `false`）**整段删除**，
   改成纯投影 `WallpaperDecision::to_prefs_patch()`（`None` / `{"sync_shell_stage_bg":true}` /
   `{"stage_index":N}`）+ `reason()` 六态诊断。**列表为空是如实跳过**（`playlist_empty`），
   不是「假装成功」。策略时钟**只在 `state_json()` 里**推进（Mod 里不起线程、不订阅事件）。
3. **记忆的注入点与时序（写死）**：订阅 `TurnPrompt` → 记住正文 → 检索 top-k →
   `apply_settings` 写**既有** `persona.system_prompt`（固定 marker，**先剥旧块再重拼**，幂等，
   重拼结果相同则**不写盘**）。**只对下一轮生效**（该事件发出时本轮请求体马上构建）——
   不写「当轮生效」的假承诺。与 `persona` Mod 是 **last-writer-wins，无仲裁**（刻意取舍，
   见 `memory-mod-v0.md` §5.1/§8）。停用时剥掉残留块。
4. **导演本轮不注册**（另一个选项「注册但 enable 即 Failed」在 RFC §8 被逐条否决：
   空工厂进静态表只会让计数断言失去意义）。RFC 同时钉死四条结构性事实（Mod 侧看不到
   token 流、无 per-request TTS 参数通道、无 `TurnEnded` 主题、`ModelActivated` 是休眠主题），
   并给出「写入者 × 字段」边界表。**动作仍只是槽位占位**，`action_tx` 保持休眠。
5. **桌宠窗口未开**（Wave 2 §3E 钉死的选项）：`window.opened` 恒 `false` +
   `reason:"native_shell_dormant"`——原生壳属休眠面，唤醒须先论证「谁来维护第二个 UI 壳」
   （`core-chain-baseline.md` §3.6）。
6. **`state_json` 是新的 Mod API 契约**：只读、须脱敏、不得阻塞；由 web_api 线程经
   `try_lock` 调用，**Mod worker 正忙时返回 503**（宁可一次读不到，也不让 HTTP 等 Mod worker）。
7. **主链与渲染面冻结**：`crates/l2d-wasm-demo/`、`stage_bg.rs`、framebuffer / 预通道 /
   `LoadOp`、壳/舞台背景、`[tts]` 端点权威——**diff 为空**。

## 5. 演示（可复制命令 + 本轮实测证据）

> 服务：`./scripts/ignite.sh`（默认 `127.0.0.1:18080`）；体检：`./scripts/ignite.sh --check`。
> 无人值守/跑测试请 `LIVE2D_AI_MUTE_AUDIO=1`。
> 以下 `$B=http://127.0.0.1:18080`；mutating 请求需 loopback `Origin` + `Content-Type: application/json`。

### 5.1 语音：sidecar → 主链开口（A 轨）

```bash
# ① 离线自检（不发任何请求）
python3 docs/examples/voice-sidecar/voice_sidecar.py --selftest
# → [selftest] 全部通过（49 项检查；离线，未发起任何请求）

# ② 干跑：看它**将要** POST 什么（不发请求）
python3 docs/examples/voice-sidecar/voice_sidecar.py \
  --audio docs/examples/voice-sidecar/fixtures/fake_zh.wav --dry-run
# → POST http://127.0.0.1:18080/api/v1/voice/transcript
#   body {"text": "把窗户关小一点"}

# ③ 真发（先启用 Mod；缺省停用）
curl -s -X POST -H 'Origin: http://127.0.0.1:18080' -H 'Content-Type: application/json' \
  --data '{}' $B/api/v1/mods/voice-input/enable
python3 docs/examples/voice-sidecar/voice_sidecar.py \
  --audio docs/examples/voice-sidecar/fixtures/fake_zh.wav
```

本轮**实测**（同一台机、活服务）：

| 步骤 | 实测 |
| --- | --- |
| Mod 停用时注入 | `403 {"error":{"code":"mod_disabled",…}}` |
| `enable` 后注入 `"  把窗户  关小一点 "` | `200 {"ok":true,"text":"把窗户 关小一点"}`（**清洗确实跑了**：折叠空白） |
| 空/零宽转写 | `400 empty_transcript` |
| 坏 Origin | `403 origin_denied` |
| **主链确实收到**（服务端日志） | `INFO mod: external-input 收到事件 turn_prompt: 把窗户 关小一点`，随后 `ERROR … TTS 阶段错误 … code=tts_transport`（**本机 CosyVoice 没起**，与本轮改动无关——恰好证明文本已进到 TTS 阶段） |

### 5.2 壁纸：决策真落偏好（B 轨）

```bash
curl -s -X POST -H 'Origin: http://127.0.0.1:18080' -H 'Content-Type: application/json' \
  --data '{"config":{"mode":"interval","interval_secs":5,"playlist_len":3}}' $B/api/v1/mods/wallpaper/config
curl -s -X POST -H 'Origin: http://127.0.0.1:18080' -H 'Content-Type: application/json' \
  --data '{}' $B/api/v1/mods/wallpaper/enable
curl -s $B/api/v1/mods/wallpaper/state
```

本轮**实测**（同一进程内相隔 6 s 的两次读取）：

```json
{"state":{"active":true,"decision":{"index":0,"kind":"advance"},"mode":"interval",
          "playlist_len":3,"prefs_patch":{"stage_index":0},"reason":"advance"}}
{"state":{"active":true,"decision":{"index":1,"kind":"advance"},"mode":"interval",
          "playlist_len":3,"prefs_patch":{"stage_index":1},"reason":"advance"}}
```

→ 索引真的在走（`0 → 1`），`prefs_patch` 就是 Flutter `applyWallpaperPatch` 的输入。
Flutter 侧把 `stage_index` 落成 `stageImage = stagePlaylist[k % len]` 并走**既有**
`Live2DStage.sendStageBg`；列表为空 → `playlist_empty` 跳过（纯逻辑在
`test/wallpaper_wiring_test.dart`，**+24 条**）。

### 5.3 记忆：写进去 → 检索出来 → 注入下一轮（C 轨）

```bash
curl -s -X POST … --data '{"config":{"store_path":"/tmp/wave2-memory.jsonl","top_k":3,"enabled_injection":true}}' $B/api/v1/mods/memory/config
curl -s -X POST … --data '{}' $B/api/v1/mods/memory/enable
# 依次注入三句（每轮之间留出上一轮收口时间）
#  → 再注入一句与第 1 句有词面重叠的（"我最喜欢的饮料是什么来着"）
curl -s $B/api/v1/mods/memory/state
```

本轮**实测**：

- `/tmp/wave2-memory.jsonl`（**真写入**）：
  `{"text":"我最喜欢的饮料是冰美式","ts":1789395734,"turn":1}` …（共 4 行）
- 第 4 轮后 `state_json`：`{"injected":1,"last_hits":1,"remembered":4,"turns_seen":4,…}`
- `live2d-ai.toml` 的 `[persona]`：
  ```toml
  system_prompt = """
  <!-- live2d-ai:memory-v0:begin -->
  - 我最喜欢的饮料是冰美式
  <!-- live2d-ai:memory-v0:end -->"""
  ```
- **停用 Mod 后**该块被剥掉（`system_prompt = ""`，marker 出现 0 次）。
- 反例同样实测：三句**互不重叠**时 `last_hits:0` → **不注入**（不是「随便塞点东西」）。

## 8. 已知缺口 / 未决（刻意，不是遗忘）

1. **端到端肉眼验收未做**（本机 CosyVoice 未起、无浏览器）：语音「真的听见皮套开口」、
   壁纸「舞台上真的换图」需要 Win/WSL 浏览器点一遍；本轮做到的是
   「文本确实进了主链并走到 TTS 阶段」（日志为证）+「决策/偏好投影有实测数据」。
2. **`memory` 的检索质量无基线评测**：Jaccard 无 idf，长记录会被稀释；
   调参前应先加固定样例对照（`memory-mod-v0.md` §9）。
3. **记忆每轮全量读 JSONL + `read_settings` 读盘**：窗口 ≤10000 条内可接受；
   JSONL 不物理删除（compaction 留 v1，须先有备份语义）。
4. **与 persona 只有 last-writer-wins**：两者都写 `persona.system_prompt`，无仲裁
   （同时启用时后写者覆盖前者的记忆块）。
5. **壁纸播放列表无删除单张 / 排序 / 缩略图**；`stagePlaylist` 与 `stageImage`
   可能重复持有同一张图（预算已计入，无去重）；`playlist_len` 是前端维护的运行值，
   Mod 面板手填会被下一次写回覆盖。
6. **`voice-input` 的 `backend`/`locale` 不参与请求**（推模式），且**没有活服务端
   端到端回归**（契约由 25 条 handler 回归 + sidecar `--selftest` 覆盖）。
7. **桌宠窗口未开**（`window.opened` 恒 `false`）；Flutter `/app/` 目前不消费该状态面
