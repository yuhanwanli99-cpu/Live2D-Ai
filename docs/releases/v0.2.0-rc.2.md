## 4. 语义钉死 / 行为变更

1. **persona 坏配置由 `Running` 变 `Failed`**（唯一用户可见的行为变更）。旧行为是
   `logger.error` + `Ok`：界面显示「运行中」，主链却一个字没变（自检说谎）。新行为符合
   `factory.rs` 对 `start` 的契约与 `mod-product-chain.md` §7 的失败隔离。影响面仅限
   「配了卡但卡坏了」的 persona 用户；该 Mod **缺省停用**，主链不受影响。
   `DESCRIPTOR.version` 语义化 bump `0.1.0` → `0.2.0`（仅 Mod 描述符，不是 crate / 全局版本）。
2. **voice-input 只注册、缺省停用**：ASR 后端尚未接线（`backend` 仅 `mock`/`sidecar`
   配置占位，**Rust 侧不开 socket、不做 IPC**）；清洗后为空的转写**不进 `say_tx`**。
   `token` 是 secret：GET 只回「是否已设置」，永不回明文。
3. **wallpaper 只注册、缺省停用**：`mode` 缺省 `off`；`WallpaperDecision` →
   `DisplayPrefs` 的落点**本轮未接**——`apply_decision` 仍是**明文占位**
   （`None` → `true`，其余 → warn + `false`），见架构文档 §5。**未新增** wasm /
   framebuffer / 时钟线程。
4. **主链与渲染面冻结**：`crates/l2d-wasm-demo/`（含 `stage_bg.rs`）、framebuffer /
   预通道 / `LoadOp`、壳/舞台背景——**diff 为空**。
5. **动作层保持休眠**：`ModServices.action_tx` 未接；director 未复活；`local-llm` 未挂回。
