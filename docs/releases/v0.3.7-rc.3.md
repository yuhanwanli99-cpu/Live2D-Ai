## 1. LLM：`[llm].mode = cloud | local`

- `LlmMode { Cloud(缺省), Local }`；`serde(default, skip_serializing_if = "is_cloud")`——
  旧 toml 无 `mode` **逐字 round-trip**（真实 `merge_into_toml` 写回逐字节断言，
  不写 `mode = "cloud"`，注释保留）。
- transport 不变：仍是同一条 OpenAI-compatible `/chat/completions`；`mode` **不参与
  `resolve`**（local/cloud 解析出的 `LlmConfig` 相同），所以 local 失败**没有**偷偷回退
  cloud 的路径。local 只表示「端点在用户自起服务上」（Ollama / llama.cpp / vLLM 等）：
  **不嵌模型、不下载权重、不加依赖、不预填厂商或 Key**。
- 切模式不动 base_url / model / max_tokens / show_reasoning / 密钥变量名 / vendor 标签与快照；
  `llm: null` 整段清空才重置回 cloud。
- 自检 `POST /api/v1/settings/test/llm` 改为 **`GET {base_url}/models`**（与 TTS 同纪律，
  mock 请求行断言不跑对话）：2xx 通、404 通 + note、401/403 `auth_failed`、其余
  `protocol_error`；local 网络不可达 = `llm_local_unreachable`（文案含「不会切回云端」），
  cloud 仍 `network_failed`/`timeout`；没配置不显示 ready。PATCH 未知 mode → 400 不写盘。
- Flutter：设置 → 模型服务 → 语言模型加「模型来源」云端/本地；本地给 Ollama
  `http://127.0.0.1:11434/v1` **示例文案**（不做硬编码下拉）；切模式只进草稿、只清厂商标签；
  旧服务端缺 mode → cloud。
- **未验**：本机没装 Ollama/本地端点，只用 mock HTTP 服务验分类；真实云端 401 未用真 key 重跑；
  设置页真 `/app` 肉眼未做（widget 测试覆盖）。

## 2. 动作 / 表情：12 → 21（D1=A 手不做）

维护者 2026-10-18 裁决 **D1=A**：不扩参数白名单（仍 13 个标准参数），
**wave / clap / point / cover_mouth / shrug 不做**，不用头身冒充手部动作。

- 新增 8 条表情：`angry` / `sad` / `blush` / `wink` / `confused` / `sleepy` /
  `excited` / `calm`；新手势 `bow`（头 Y −12 / 身 Y −3.9 / 1600ms，比 nod 更深更慢）。
- 全部只用现有 13 参数；表情 = 五官 + 小幅头身，按 `scales.rs` 三旋钮标定
  （不超头 30 / 身 10 / 五官 4；死区起点 >2.2）。
- 四处单一真源 **21 条**：runtime `PRESET_IDS`/`preset_slot`/`EXPRESSION_PRESET_IDS`
  （12 表情 + 9 手势）↔ `presets.json`（21）↔ `preset_labels.json`（22 = 21 + none）↔
  wasm 内建 fallback / field map。四向一致 + 每条 apply/revoke/ttl（21 × 2 表）+ D1
  白名单/手包缺席断言全绿。
- 默认 emotion → preset 映射**未改**（仍 smile/unhappy/surprised/nod）：新 id 是面板 /
  表演层能力集，不改变导演既有行为。
- 真机 bai（`/render`，外置表 21 条）逐条肉眼 + 像素差全非 0、19 条 preset ack 全 applied；
  **Epsilon_free 不可验**：其参数是旧式大写 `PARAM_ANGLE_X` 等，不含 13 标准参数，
  本动作系统按既有规则丢弃（`preset-dropped degraded=true reason="ParamAngleX"`），
  不是本块回归，也不加 remap 表。
- **未验**：Flutter GUI 新标签实显、新 id 与 0.3.6 热换模/epoch 的浏览器联合路径、
  两旋钮同时拉满的真机现场（单测已钉）。
