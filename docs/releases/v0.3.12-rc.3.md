## 1. rc.1 只读清单预检（提交 `acc9ea4`）

- 新 `crates/live2d-ai-desktop/src/mods_scan.rs`：扫描根 = **进程当前目录**下的 `mods/`，
  只看下一层 `mods/<目录名>/mod.toml`；目录不存在 = 已发现 0（**不创建**它）。
  以 `.` 开头的目录跳过；不跟随符号链接（目录或清单本身是链接 = 不可用，原因写明）。
- 字段表按执行单 `3：`schema = 1`、`id` 正则且等于目录名、`name` / `version` 非空、
  `api_version` = `MOD_API_VERSION`（1）、`kind ∈ process|launcher`、`description` 可选、
  `entry` / `launch.program` / `launch.mode`。未知键（含 `[permissions]`）=
  这份清单不可用。
- `entry` / `launch.program` 只做**词法 + 规范化**检查：必须是该 Mod 目录内的相对路径、
  普通文件、不跟随符号链接；**不要求可执行位，不执行**。
- 保留 id（`director` / `local-llm` / `wallpaper` / `pet-desktop` / `local-tts`）不可选；
  与已编进二进制工厂 id 冲突的文件夹不可选；同一 id 出现两次时路径排序第一份留下、
  其余「重复」。
- 新 `mods_scan_toml.rs`：严格 TOML 子集解析（失败关闭）。**不新增 desktop 依赖**——
  顶层 `[dependencies]` 仍 **18** 条。
- 新只读路由 `GET /api/v1/mods/discovered`（`{"discovered":[…]}`，每行带
  `selectable` / `reason` / `enabled`）。文件夹行**不进** `GET /api/v1/mods`
  （那个列表仍只代表工厂）。
- `ModRegistry::persist_folder_selection`：只覆写这些文件夹 id 的 `enabled`，
  其余 id / 键原样保留，无变化不写盘；未注入 manifest 路径 = no-op。
  `POST /api/v1/mods/discovered`（loopback Origin + `application/json`）只记勾选，
  **不** enable / disable、**不** spawn。
- `.gitignore` 增加 `/mods/`（`/mods.json` 规则不动）。测试夹具只在临时目录，
  仓库里没有 `mods/<id>/` 样例。
