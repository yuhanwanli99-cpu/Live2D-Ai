# Live2D-Ai PC v0.2.0-preview.1

Status: source-only PC Preview. Supported targets are WSL2 and Ubuntu/Linux. Native Windows is unsupported; macOS is untested; Android is not part of this release.

## Highlights

- Deterministic semantic Live2D choreography: the director selects an action label while the renderer owns safe timing, amplitude, release, and gaze centering.
- Motion strength 1/2/3 reaches the renderer and produces visibly different amplitudes.
- The persistent lower-left gaze failure is prevented by rejecting LLM continuous gaze output and returning deterministic gaze tracks to center.
- Settings HTTP architecture is split into domain modules; the legacy routes module is now a compatibility export only.
- Settings fetch calls are centralized through the renderer API client.
- Fresh source archives bind to 127.0.0.1, disable heavyweight ASR downloads by default, create the model import directory, and start without an API key or bundled model.
- Standard AGPL-3.0-only licensing with an optional separate commercial license for proprietary use.

## Known limitations

- No bundled model means the first run requires a lawful local model import.
- The release is source-only; there is no signed desktop installer or auto-updater.
- The renderer main chunk remains larger than 500 kB and will be code-split in a later release.
- Pydantic emits forward-looking deprecation warnings that do not affect Python 3.12 Preview operation.
- The current release uses deterministic semantic motion. Constrained LLM pose micro-adjustment is planned for the second stable release.
