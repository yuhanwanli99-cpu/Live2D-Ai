## 这一版

1. **导演 Mod 关（缺省）**：主链仍是「文本 → 一路 LLM → 按句清洗 → TTS → 口型 → Live2D」。
   待机呼吸 / 眨眼还在；**不出**导演 `action_cue`。
2. **导演 Mod 开，且 `staging_*` 两项都空 / 都有**（动作门）：每一句仍只有**一次**按句清洗请求。
   `speech` 送 TTS；**同一次响应**多带这份 `cues`，依据是**这一句一路原文**（不是 `speech`、
   不是用户输入）。清洗失败（超时 / 非 2xx / 坏 JSON / `display` 不是原文切片）→ `display = speech = 原文`，
   再用**这一句原文**查规则表。合法 JSON 里 `cues: []` = 这句不动，不回退规则表。
3. **只填一个 `staging_*`（`Incomplete`）保持旧行为**：清洗仍走主 LLM、不带 `cues`，
   Mod 规则层仍按**用户句**出第一句 cue（已知边界，见下）。
4. **出厂不设人设**：`system_prompt` 为空；`shared/persona.yaml` 删除；`live2d-ai-mod-persona`
   保留（用户自己启用后导入角色卡）。
5. **待机**：`final_override` 到点撤销后呼吸 / 眨眼回来；本轮**没有**新的粘滞复现
   （`pose_stack` 的 `idle_drives_breath_and_is_not_stuck_after_clear` 与
   `override_layer_beats_everything_and_clear_restores` 继续绿）。cue 不写 `ParamMouthOpenY`，也不 `hold`。
