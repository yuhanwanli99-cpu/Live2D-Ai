## 1. 这一版是什么

`rc.7` 之后的第一次**收口 + 去臃肿**。三件事：
1. **文档治理（S0）**：`docs/plans` 从 118 份降到 **24 份**（94 份历史候选归档到 `docs/legacy/plans/`），
   AGENTS.md 单⼀化（`-Ai` 旧副本标为历史）、CHANGELOG 停用、`v0.3.0.md` 标「历史草案」。
2. **正确性与诚实性（rc.8-a）**：45 条前端审计里**剩余可修的 12 条**（4 条 P1 + 8 条 P2/P3）逐条红-绿闭环，
   **测试 1378 → 1524（+146）**。
3. **去臃肿 D0/D1/D3（部分）**：新增度量门禁（含 CI 三条硬门禁）、**休眠资产两段式清理**（最大单项）、
   测试侧重复消除（8 份副本 → 1）。

**没做的**（如实写在 §6）：D2 结构拆分、D4 依赖收尾（差 3 条）、D5 文档总量瘦身、D6 测试治理。
所以**本版不是「0.2.0 全部工程债清零」**，而是「收口完成 + 去臃肿第一轮落地」。

### 5.2 去臃肿 D0 / D1 / D3

- **D0 度量门禁**：新增 `cargo run -p xtask -- code-stats`（逐 crate prod/内联/集成 + Dart + docs +
  超限清单 + 依赖数 + 产物体积，输出 markdown）与 `--check`；CI 接**三条硬门禁**（`--only lines` /
  `--only over-1000` / `--only deps`）。**阈值取「棘轮」= 立档实测**，并立下**只降不升**纪律：
  任何让计数下降的 commit **必须在同一 commit 收紧棘轮**。
- **D1 休眠资产两段式**（维护者裁决，红线修订见阶段报告 §4）：
  - **第一段**：删除 3 个**早已不在 `AVAILABLE_MOD_FACTORIES`** 的已归档 Mod crate
    （`local-llm` / `wallpaper` / `pet-desktop`）——零主链触点，退出测试 **64** 条全部落在被删 crate，
    **主链集合差 = 0**；
  - **第二段**：物理移出原生壳岛 + 连带集（`app/` `benchmark/` `model_smoke/` `tray/` `repl.rs`
    `adapter/` `backend/` `user_event.rs` `platform/window.rs` `cli/path_resolve.rs`，31 文件 ≈8,954 行），
    退出测试 **111** 条（100 ⊆ 被移出目录；11 条住在保留文件里、测的是**已随壳删除的对象**——leader 签署）；
    `desktop` 依赖 **34 → 25**，休眠岛行数**归零**。台账：
    [`docs/architecture/ARCHIVED-mods.md`](../architecture/ARCHIVED-mods.md) §1.4/§2.4/§3.1 +
    [`docs/architecture/ARCHIVED-native-shell.md`](../architecture/ARCHIVED-native-shell.md)（含 111 条全名 +
    恢复步骤 = 回到 tag `checkpoint/pre-d1-dormant` = `d140604f`）。
  - **主链触点 5 处（全部记录在案）**：`app_event.rs` 的 `Tray(PetUserEvent)` 变体 / `send_app_event()` /
    该 use · `web_api/ws/events.rs` 的 `AppEvent::Tray(_)` **不投影臂**（**零帧变化**）·
    `supervisor.rs` 一处测试样本换等价物。**对外 WS 帧类型名与字段名一律未动。**
- **D3 重复消除**：测试侧 `stripCommentsAndStrings` **8 份副本 → 1**（`test/support/source_scan.dart`）
  + **反复制门禁**（定义点必须唯一，带防零命中空转与「判据是定义不是提到」两道自保）。
  **实证**：8 份里 7 份 sha1 相同、**1 份漂移**（`design_tokens_test.dart` 写成占位符 `S`），
  而**恰好是它**被 3 个文件 `show` 走 —— 「重复必然漂移」。
  D3 原点的生产侧副本（`formatWsError`/`decodeDataUrl`/`redact`/`effective_token`）**实测已是单一定义**，未硬造合并。
