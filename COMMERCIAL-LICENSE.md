Live2D-Ai project-owned code is public under **AGPL-3.0-only** alone, including for commercial use when the AGPL terms are followed. There is no second public license for project-owned code.

If an organization wants to avoid the AGPL source-availability obligations (for example, to incorporate project-owned code into proprietary software or hosted services), that requires **commercial payment plus a separate written agreement** with the copyright holder — not a different public license. Scope, support, warranty, and pricing are set only in that written agreement. Contact QQ `338438383`.

This option does not restrict or revoke rights already granted by AGPL-3.0-only, and does not relicense third-party components, fonts, the render stack, or model assets.
